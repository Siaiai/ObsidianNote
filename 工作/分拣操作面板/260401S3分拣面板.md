## 2. 架构与协议

### 2.1 分层

| 层 | 目录 | 职责 |
|---|---|---|
| 硬件 | `01_Hardware/bsp`、`component/*`、`adapt/*` | 时钟/SysTick/USART/SPI/LCD/Flash/按键 |
| GUI | `02_Middleware/GUI` | 无 malloc GUI、焦点/列表/弹窗、Win32 模拟器 |
| 模型 | `02_Middleware/panel_model` | JSON 解析、参数模型、UI 元数据、值池/值源 |
| 协议 | `02_Middleware/my_protocol` | 二进制帧、命令注册、ACK/分片 |
| 应用 | `04_Application/app`、`ui_pages` | 面板协议、参数 glue、页面 |

### 2.2 主循环

```text
Clk → SysTick → LED → USART1 → ST75256 → W25Qxx
App_LogInit → App_UIInit → App_FontInit → App_JsonCacheInit
→ App_KeyInit → App_PanelInit → App_ParamInit
主循环：
App_KeyProcess → App_PanelLoop(心跳/JSON_VERSION/分片拉取/命令)
→ App_ParamLoop(ready 后解析一次) → App_LogLoop → UI_Loop
```

约定：

- JSON 缓冲借用面板 RX 缓冲，解析后只读，重拉前复位模型。
- 参数顺序 = JSON 实参顺序；`length=1/2B`，u16 大端。
- 页面/`ParamStore` 通道 0-based，协议通道 1-based（`ch+1`）。
- 失败统一 `[0x00][idx][reason]`：写入失败 `idx` 1-based，其他为 0；reason UTF-8、最多 64B；面板原样显示，不按文本做逻辑。详细错误由 `paramConfigSetEx()`/`ParamSetResult_t` 提供，旧 `paramConfigSet()` 保持给 UDP 0x0B。
- 20px 字体；缺字回退内置 5×7。

### 2.3 协议

| CMD | 名称 | 方向 | 说明 |
|---|---|---|---|
| `0x0001` | HEARTBEAT | 面板→控制器 | 回版本串；面板连接态由控制器 `panel_State` 维护 |
| `0x0002` | JSON | 双向 | `[seq]` 请求分片；回 `[seq][total][data...]` |
| `0x0003` | READ_VALS | 面板→控制器 | `[mod][ch]`；成功 `[0xAA][values...]` |
| `0x0004` | WRITE_VALS | 面板→控制器 | `[mod][ch][values...]`；成功回显 |
| `0x0005` | SET_ENABLE | 面板→控制器 | `[mod][ch][en]` |
| `0x0006` | READ_ENABLE | 面板→控制器 | `[mod]`；0=全部 |
| `0x0007` | NETCONF_STAGE | 面板→控制器 | `sub=1~5`；`sub=5` 为本地 IP 四段（a.b.c.d） |
| `0x0008` | NETCONF_CONFIRM | 面板→控制器 | `[sub][0xAA]`，写 Flash 后复位生效 |
| `0x0009` | JSON_VERSION | 面板→控制器 | `[0xAA][crc32:4][len:2]` |
| `0x000A` | SWITCH_SET | 面板→控制器 | `[mod][ch][len][data...]` |
| `0x000B` | SWITCH_GET | 面板→控制器 | `[mod][ch]` |
| `0x0010` | DEBUG_GET | 面板→控制器 | `[0xAA][active]` |
| `0x0011` | DEBUG_SET | 面板→控制器 | `[0/1]` |
| `0x0012` | DEBUG_READ_INPUTS | 面板→控制器 | `[0xAA][18B]` 单次快照 |
| `0x0013` | DEBUG_PULSE_OUTPUT | 面板→控制器 | `[port]`，2s 自动关 |
| `0x0014` | DEBUG_OUTPUT_OFF | 面板→控制器 | 关闭当前点动 |
| `0x0015` | DEBUG_READERS | 面板→控制器 | 读卡器快照（当前未实现） |
| `0x0016` | DEBUG_INPUT_EVT | 控制器→面板 | 输入变化推送，18B |
| `0x0017` | DEBUG_READERS_EVT | 控制器→面板 | 读卡器变化推送（当前未实现） |
| `0x0018` | DEBUG_STATE_EVT | 控制器→面板 | 调试状态变化 |

### 2.4 控制器调试/输入现状

- 调试开关：面板/UDP 都调 `postDebugModeSet()` → `SIG_SYS_DEBUG_ON/OFF` → `ao_sys`。
- 输出点动：面板/UDP 都调 `postDebugOutputOpen/Close()` → `ao_sys`；2s 定时在 `ao_sys`。
- 输入：`debugGetInputSnapshot()` 只读一次快照；`debugReportInputs()` 同点发 UDP `0x90` + 面板 `0x0016`；面板侧不再轮询读口。
- 面板通信 API 已统一为 `PanelCommInit`/`PanelCommProcess`；事件广播用 `panelBroadcastEvent()`，避免和 UART 发送混淆。

### 2.5 页面/按键契约

- 列表只有 `SELECTED` 时高亮当前行；页面切焦点时同步 `SELECTED`。
- 模块页双通道：TabBar 左右切通道；列表聚焦、非编辑时左右切通道；`s_ch_row[2]` 分别记行号。
- 单通道模块忽略左右；加载/保存中冻结切换；dirty 时先确认。
- 编辑中左右归参数编辑器（左=退格，右=吞掉），不切通道。
- 运行开关 F2 进入，F1 编辑/Enter 下发/F3 重读。
