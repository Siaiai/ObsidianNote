## 2. 契约 v1（2026-10-30）

- **分层**：硬件（`01_Hardware`）→ GUI / panel_model / my_protocol（`02_Middleware`）→ 应用（`04_Application`）。
- **硬件访问**：只经 ops 表（`ST75256_Ops_t`、`W25Qxx_*`、`UI_Ops_t`）；寄存器只出现在 `st75256_hc32_adapter.c`、`app_ui.c`。
- **通道基准**：页面与 `ParamStore` 0-based；协议 1-based（`ch+1`）。
- **JSON**：缓冲借用面板 RX 缓冲，解析后只读；参数顺序 = JSON 实参顺序；`length=1/2B`，u16 大端。
- **失败格式**：`[0x00][idx][reason]`；写入失败 `idx` 1-based，其它为 0；reason UTF-8、最多 64B，面板原样显示。
- **协议头**：`04_Application/app/panel_cmd.h` 与控制器 `APP/panel/panel_cmd.h` 必须字节一致，由 `panel_cmd` 测试校验。
- **UI 事件码**：`eKeyLight`（照明键）只由模块页消费，用于显示当前参数 `remark`（← C1）。
- **Flash 分区**：JSON A/B 槽 `0x00F00000` / `0x00F10000`，自检扇区 `0x00F9F000`；字体区低于 `0x00F00000`。
- **时基**：`Bsp_GetTickMs()` 为全局 1ms 时基；`Bsp_SysTickInit()` 必须在 `Bsp_ClkInit()` 之后。
- **非阻塞**：主循环各 `*Loop` 不得阻塞。
- **构建**：Keil / EIDE 新增源文件双登记；EIDE 优先用 MCP 工具（`eide_build` / `eide_flash` 等），不直接改 `.eide/eide.yml`；必须改时先 `eide_reload`。MCP 不可用时先报告服务问题，不自动回退 shell 构建 / 烧录。

## 3. 设计要点

### 3.1 分层与数据流

```mermaid
flowchart LR
    C[控制器] -- 二进制帧 --> P[app_panel]
    P --> S[param_source_protocol]
    S --> M[panel_model]
    J[UI.JSON] --> M
    M --> PG[ui_pages]
    PG --> G[GUI]
    G --> U[app_ui]
    U --> L[ST75256]
    P <--> F[app_json_cache]
    F --> W[W25Qxx]
```

- 主循环：`App_KeyProcess` → `App_PanelLoop`（心跳 / JSON / 分片 / 命令）→ `App_ParamLoop`（JSON ready 后解析一次）→ `App_LogLoop` → `UI_Loop`。
- 页面只读模型 / 值池，写经 `ParamSource`；页面不直接拼协议字节。

### 3.2 页面焦点与状态

- 列表只有 `SELECTED` 时高亮当前行；页面切焦点同步 `SELECTED`。
- 模块页每通道独立行号；单通道忽略左右；编辑中左右归参数编辑器。
- 页面状态契约集中在 `04_Application/ui_pages/page_state.h`，页面不各存一套。

### 3.3 照明键参数提示（R1）

- 入口：`KEY_Light`（`app_key.h`）当前未映射；新增 `eKeyLight`，`app_key.c` 映射，模块页页级事件处理。
- 取值：`s_list.focused_index` → `s_flat_idx[row]` → `PModParam_t.remark`（JSON span，非 NUL）。
- 展示：`copy_span` 到 192B 静态缓冲（`参数名\n备注`，UTF-8 边界截断）；`UI_PopupShow(..., BTN_NONE, PRIO_INFO, 0, &module_page, ...)` 常驻，Cancel 关闭；空 remark 改 `UI_PopupToast("无备注", 800)`。
- 测试：`ui_min.json` 模块 4 第一条加 `remark`，第二条保持空；新增 `panel_ui_light_hint` 覆盖有值弹窗、空值 toast、Cancel 关闭。
- 编辑态：`UI_Param` 编辑中吞掉非编辑键，照明键不弹提示，不改编辑器。
- 边界：仅模块参数页；网络页 IP 行聚合多参数、整页汇总、长按连发、协议改动不做。
- 机制：复用 GUI 事件路由 / Popup / ParamModel remark；不新建机制（D2）。
