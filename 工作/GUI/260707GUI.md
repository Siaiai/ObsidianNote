## 2. 契约 v1（2026-10-30）

- **运行模型**：单线程、事件驱动、三阶段循环；库内不使用 `malloc`，容量编译期固定。
- **组件**：首成员必须是 `UI_CompBase_t`；每类型一个静态 vtable；绘制只走 `*Clipped`，内容区用 `UI_CompContentRect`。
- **页面**：固定深度栈；根页拒绝 Pop；Push / Pop / Switch 先关闭绑定弹窗；焦点变化请求刷新。
- **事件**：单一枚举 + 固定队列；实例表 → vtable → 页面表 → 内置导航 → 全局默认；返回 1 停止冒泡；阻塞弹窗冻结页面，Toast 不冻结。
- **弹窗**：固定池 + 优先级栈；只绘制当前选中；`bind_page` 必须是活动页；关闭顺序为移除 → `on_close` → confirm/cancel → 释放槽。
- **参数**：`value` 只在提交时写回；范围 / 格式校验由调用方提供；`cursor_move` 选择光标移动模式。
- **字体**：UTF-8 解码；可选 `UI_SetFontOps` 外部字库；无字库回退内置 5×7。
- **屏幕 / HAL**：240×160 单色（文档截图按 2× 输出 480×320）；HAL 恰为 `UI_Ops_t` 四回调。
- **构建与测试**：`cmake -B build`、`cmake --build build --config Debug`、`ctest --test-dir build --output-on-failure`。
