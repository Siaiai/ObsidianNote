## 一、主动行为（上电即运行，不依赖上位机）

### 1.4 卡号校验：仅两关

```mermaid
flowchart TD
    Start("decode_end_flag == 1<br/>64 位数据完整") --> Pause["CR = 0<br/>暂停 PCA (125kHz 停振)"]

    Pause --> RowCheck["行校验: 10 行奇校验<br/>每行 4 位数据 XOR<br/>与第 5 位校验位比较"]
    RowCheck --> ColCheck["列校验: 4 列奇校验<br/>每列 10 位数据 XOR<br/>与校验位比较"]

    ColCheck --> Result{"Data_hang_check_num == 10<br/>且<br/>Data_lie_check_num == 4 ?"}

    Result -->|"通过"| Pass["Data_check_flag = 1<br/>LED_GREEN = 0 绿灯亮"]
    Result -->|"失败"| Fail["Data_check_flag = 0<br/>CR = 1 恢复 PCA"]

    Pass --> Resume["CR = 1 恢复 PCA"]
    Fail --> End(["返回"])

    Resume --> Extract["进入 Data_processing<br/>提取卡号"]
    Extract --> End

    style Pass fill:#50B86C,color:#fff
    style Fail fill:#D94A4A,color:#fff
```

**第一代缺少的校验：** 无停止位校验（Bit[63]==0）、无卡号全零过滤。

### 1.5 卡号提取与变化检测（核心上报逻辑）

```mermaid
flowchart TD
    Entry("Data_check_flag == 1") --> Extract["从 64 位原始数据提取 5 字节卡号<br/>存入 FirstLu_Kahao_buffer[3..7]"]
    Extract --> NotZero{"卡号不全为零?"}

    NotZero -->|"否"| OffLED["LED_GREEN = 1 绿灯灭<br/>Read_card_success_flag = 0"]
    NotZero -->|"是"| Compare{"卡号 buffer[4..7]<br/>与上次基准 buffer2[4..7]<br/>比较"}

    Compare -->|"不同"| SetNew["Kahao_new_flag = 1<br/>将新卡号存入 buffer2 作为基准"]
    Compare -->|"相同"| CheckCond

    SetNew --> CheckCond{"Read_card_success_flag == 0<br/>或 Kahao_new_flag != 0 ?"}

    CheckCond -->|"是"| Trigger["触发上报"]
    CheckCond -->|"否"| Skip["不触发<br/>(同一张卡, 去重)"]
    Skip --> Out(["返回"])

    Trigger --> Busy{"B_TX1_Busy ?"}
    Busy -->|"是"| Wait["delay_ms(20)<br/>等待串口空闲"]
    Busy -->|"否"| SetFlags
    Wait --> SetFlags["B_TX1_Busy = 1<br/>Read_card_first_flag = 1"]

    SetFlags --> Manner{"Send_Manner ?"}

    Manner -->|"0x55 进站"| Set100ms["Read_card_100ms_flag = 1<br/>启动 100ms 二次发送定时"]
    Manner -->|"0xAA 下放"| No100ms["不设 100ms 标志<br/>仅一次发送"]

    Set100ms --> Send["SBUF = buffer[0]<br/>TX_DATA_NUM = 1<br/>启动 TI 中断逐字节发送"]
    No100ms --> Send

    Send --> LED["LED_GREEN = 0<br/>Read_card_success_timer = 0"]

    style Trigger fill:#D94A4A,color:#fff
    style Set100ms fill:#4A90D9,color:#fff
    style Skip fill:#999,color:#fff
```

**关键：** 卡号变化时**不等上位机轮询，立即通过 TI 中断逐字节发送**。

### 1.6 Timer0 ISR（10ms 节拍驱动所有定时）

```mermaid
flowchart TD
    ISR("Timer0 中断 (每 10ms)") --> F1{"Read_card_100ms_flag?"}

    F1 -->|"== 1<br/>正在等待二次发送"| Wait100["Read_card_100ms_timer++"]
    Wait100 --> C1{"timer >= 10 ?<br/>(100ms)"}
    C1 -->|"否"| Exit
    C1 -->|"是"| Trigger2["Read_card_100ms_flag = 2<br/>SBUF = buffer2[0]<br/>TX_DATA_NUM = 1<br/>B_TX1_Busy = 1<br/>→ 二次发送同一卡号"]
    Trigger2 --> Exit

    F1 -->|"== 3<br/>二次发送完成, 冷却中"| Cool["Read_card_100ms_timer++"]
    Cool --> C2{"timer >= 5 ?<br/>(50ms)"}
    C2 -->|"否"| Exit
    C2 -->|"是"| CoolEnd["Read_card_100ms_flag = 0<br/>冷却结束, 恢复指令响应"]
    CoolEnd --> Exit

    F1 -->|"== 0 或 == 2"| F2{"Read_card_success_flag?"}

    F2 -->|"!= 0 有卡"| Timeout["Read_card_success_timer++"]
    Timeout --> C3{"timer >= 20 ?<br/>(200ms)"}
    C3 -->|"否"| Exit
    C3 -->|"是"| Clear["LED_GREEN = 1 绿灯灭<br/>Read_card_success_timer = 0<br/>Read_card_success_flag = 0<br/>→ 卡超时清零"]
    Clear --> Exit

    F2 -->|"== 0 无卡"| ResetTimer["Read_card_success_timer = 0"]
    ResetTimer --> Exit(["返回"])

    style Trigger2 fill:#E8A838,color:#fff
    style Clear fill:#D94A4A,color:#fff
    style CoolEnd fill:#50B86C,color:#fff
```

### 1.7 UART TI 中断（逐字节发送状态机）

```mermaid
flowchart TD
    TI("TI 中断 (发送完成)") --> F1{"哪个标志位?"}

    F1 -->|"Read_card_first_flag == 1<br/>新卡首次发送"| Send1["uart_send_data(buffer, 8)<br/>逐字节装载 SBUF"]
    Send1 --> Done1{"TX_DATA_OVER ?"}
    Done1 -->|"否 (继续)"| Exit(["返回"])
    Done1 -->|"是 (8 字节完)"| Clear1["Read_card_first_flag = 0<br/>B_TX1_Busy = 0<br/>TX_DATA_OVER = 0"]

    F1 -->|"Read_card_100ms_flag == 2<br/>进站 100ms 二次发送"| Send2["uart_send_data(buffer2, 8)"]
    Send2 --> Done2{"TX_DATA_OVER ?"}
    Done2 -->|"否"| Exit
    Done2 -->|"是"| Clear2["Read_card_100ms_flag = 3<br/>B_TX1_Busy = 0<br/>TX_DATA_OVER = 0<br/>→ 进入 50ms 冷却"]

    F1 -->|"Send_card_500ms_flag<br/>0x75 应答有卡"| Send3["uart_send_data(buffer, 8)"]
    Send3 --> Done3{"TX_DATA_OVER ?"}
    Done3 -->|"否"| Exit
    Done3 -->|"是"| Clear3["Send_card_500ms_flag = 0<br/>B_TX1_Busy = 0"]

    F1 -->|"Send_err_500ms_flag<br/>0x7A / 0x75 无卡"| Send4["uart_send_data(ERR, 7)"]
    Send4 --> Done4{"TX_DATA_OVER ?"}
    Done4 -->|"否"| Exit
    Done4 -->|"是"| Clear4["Send_err_500ms_flag = 0<br/>B_TX1_Busy = 0"]

    style Clear2 fill:#E8A838,color:#fff
    style Clear3 fill:#50B86C,color:#fff
    style Clear4 fill:#4A90D9,color:#fff
```

> `uart_send_data` 逻辑：`TX_DATA_NUM < data_len` → 装入 SBUF, 递增；`TX_DATA_NUM >= data_len` → 置 `TX_DATA_OVER = 1`。

### 2.1 命令接收（UART RI 中断 3 字节状态机）

### 2.2 0x7A —— 进站

```mermaid
flowchart TD
    Cmd7A("收到 0x10 0xFF 0x7A") --> SetDir{"Send_Manner != 0x55 ?"}
    SetDir -->|"是"| Set55["Send_Manner = 0x55"]
    SetDir -->|"否"| BusyCheck
    Set55 --> BusyCheck{"Read_card_100ms_flag != 0<br/>或 B_TX1_Busy != 0 ?"}

    BusyCheck -->|"是 正在忙"| Ignore["静默忽略<br/>不发送任何应答"]
    BusyCheck -->|"否 空闲"| SendErr["B_TX1_Busy = 1<br/>Send_err_500ms_flag = 1<br/>SBUF = FirstLu_Send_ERR[0]<br/>TX_DATA_NUM = 1"]
    SendErr --> Result["→ TI 中断发送 7 字节 Fail 包"]

    style Ignore fill:#999,color:#fff
    style Result fill:#D94A4A,color:#fff
```

**0x7A 不查询卡号，只应答 Fail。** 卡号已在检测到新卡时主动上报过了。

### 2.3 0x75 —— 下放

```mermaid
flowchart TD
    Cmd75("收到 0x10 0xFF 0x75") --> SetDir{"Send_Manner != 0xAA ?"}
    SetDir -->|"是"| SetAA["Send_Manner = 0xAA"]
    SetDir -->|"否"| BusyCheck
    SetAA --> BusyCheck{"Read_card_100ms_flag != 0<br/>或 B_TX1_Busy != 0 ?"}

    BusyCheck -->|"是 正在忙"| Ignore["静默忽略"]

    BusyCheck -->|"否 空闲"| HasCard{"Read_card_success_flag != 0 ?"}

    HasCard -->|"是 有卡"| SendCard["B_TX1_Busy = 1<br/>Send_card_500ms_flag = 1<br/>SBUF = FirstLu_Kahao_buffer[0]<br/>→ 发送 8 字节卡号包"]

    HasCard -->|"否 无卡"| SendFail["B_TX1_Busy = 1<br/>Send_err_500ms_flag = 1<br/>SBUF = FirstLu_Send_ERR[0]<br/>→ 发送 7 字节 Fail 包"]

    style SendCard fill:#50B86C,color:#fff
    style SendFail fill:#D94A4A,color:#fff
    style Ignore fill:#999,color:#fff
```

**0x75 可查询当前卡号。** 适用于需要主动获知"工位上现在有没有衣架"的场景。

## 三、完整行为时序

### 3.1 进站场景（Send_Manner = 0x55）

```mermaid
sequenceDiagram
    participant Tag as 衣架标签
    participant Reader as 读卡器
    participant Host as 上位机

    Note over Reader: 后台: 持续 125kHz 载波 + 解码

    Tag->>Reader: 进入感应区

    Note over Reader: 解码完成, 校验通过<br/>LED_GREEN=0 绿灯亮

    Reader->>Reader: 卡号与上次不同 → 触发上报
    Reader->>Host: 立即: 0x10 0xFF 0x05 + 5 字节卡号 (8 字节)

    rect rgb(255, 245, 230)
        Note over Reader: Read_card_100ms_flag=1 (进站方向)
        Note over Reader: 100ms 后...
        Reader->>Host: 二次: 0x10 0xFF 0x05 + 同一卡号 (8 字节)
        Note over Reader: Read_card_100ms_flag=3 (50ms 冷却)
    end

    Note over Reader: 冷却结束, Read_card_100ms_flag=0

    rect rgb(240, 255, 240)
        Note over Host,Reader: 上位机轮询 (冷却结束后)
        Host->>Reader: 0x7A (进站)
        Reader->>Host: Fail 7 字节 (心跳确认)
    end

    Note over Tag,Reader: 同一标签仍在感应区
    Note over Reader: 每轮解码卡号 = 上次基准 → 不触发上报

    Note over Reader: 200ms 无新解码 → LED_GREEN=1<br/>Read_card_success_flag=0

    Tag-->>Reader: 离开感应区
    Host->>Reader: 0x7A
    Reader->>Host: Fail 7 字节
```

### 3.2 下放场景（Send_Manner = 0xAA）
