# SR2 读卡器（第一代 STC15）行为规范

> 源码: `RFID_STC15_C语言（EM4095收指令发）(2)\main.c`（约 640 行，单文件）
> MCU: STC15W4K32S4, 29.4912MHz, 12T 模式
> 用途: 重构第三代时确保向下兼容的基线参考

---

## 一、主动行为（上电即运行，不依赖上位机）

### 1.1 上电初始化

```
1. Timer0 初始化 (10ms 自动重装, 12T 模式)
2. PCA 初始化 (125kHz 方波输出, 1T 模式)
3. UART1 初始化 (19200-8-N-1, P30/P31, Timer2 波特率)
4. GPIO 初始化 (P1.2 红灯推挽, P1.3 绿灯推挽, P3.3 SHD 推挽)
5. EM4095 初始化: SHD=1, delay 50ms, SHD=0, delay 50ms
6. LED 初始态: 绿灯灭 (LED_GREEN=1), 红灯亮 (LED_RED=0)
7. 帧头预填充: FirstLu_Kahao_buffer[0..2] = 0x10,0xFF,0x05
8. EA=1 开全局中断
```

### 1.2 主循环（无止境运行）

```
while(1):
    decode_125kCard()     → 曼彻斯特解码
    Data_check()          → 行校验 + 列校验
    Data_processing()     → 提取卡号 → 变化检测 → 触发上报
```

**无看门狗**（WDT_CONTR 被注释掉）。

### 1.3 125kHz 载波

PCA 模块 1 配置为高速脉冲输出模式（`PCA_Mode_HighPulseOutput`），1T 时钟，自动映射到 P1.0 硬件引脚。中断中通过 `CCAP1_tmp += PWM_DUTY`（118）动态调整占空比。

每 125kHz 周期执行：`decode_num++`，监控 DMOD_OUT (P3.2) 边沿。

### 1.4 曼彻斯特解码

监控 DMOD_OUT 引脚电平跳变：
- 跳变时记录 `FirstLu_Counter_Buffer = decode_num`（脉宽计数值）
- `decode_num` 清零重计
- `decode_stick_flag = 1`（通知主循环有新脉宽数据）

脉宽分类（单位：PCA 1T 计数，29.4912MHz → 约 33.9ns/step）：
- 窄脉冲: `Width1_low=35` ~ `Width1_hight=95`（约 1.2μs ~ 3.2μs）
- 宽脉冲: `Width2_low=105` ~ `Width2_hight=175`（约 3.6μs ~ 5.9μs）
- 超出范围 → `decode_cnt = 0`（复位解码器）

单电平/双电平解码逻辑（`N1_01_SYS` 空跳补偿、曼彻斯特规则还原 64 位）。前 9 位必须全 1（否则 `decode_cnt=0` 复位）。

### 1.5 卡号校验：仅两关

**行校验（10 行奇校验）：**
```
for i = 0..9:
    行 i: decode_data[9+5i+3] XOR decode_data[9+5i+2] XOR decode_data[9+5i+1] XOR decode_data[9+5i]
    校验位: decode_data[9+5i+4]
    比较 → Data_hang_check_num++
```

**列校验（4 列奇校验）：**
```
for i = 0..3:
    列 i: 10 位 XOR
    校验位: decode_data[9+i+50]
    比较 → Data_lie_check_num++
```

**通过条件：** `Data_hang_check_num==10 && Data_lie_check_num==4`

**没有：** 停止位校验、卡号全零过滤。

校验期间 CR=0（PCA 暂停，125kHz 载波停振）。校验通过或失败后 CR=1（恢复）。

### 1.6 卡号提取

```
CardData[3] = decode_data[9..17]  (含行校验位跳过)
CardData[4] = decode_data[19..27]
CardData[5] = decode_data[29..37]
CardData[6] = decode_data[39..47]
CardData[7] = decode_data[49..57]
```

存入 `FirstLu_Kahao_buffer[3..7]`（[0..2] 已在初始化时预填 0x10,0xFF,0x05）。

### 1.7 卡号变化检测与立即上报

校验通过后 `LED_GREEN=0`（绿灯亮），然后比较卡号：

```
if CardData[4..7] != LastCardData[4..7]:
    Kahao_new_flag = 1
    将新卡号存入 FirstLu_Kahao_buffer2（基准）

if Read_card_success_flag==0 || Kahao_new_flag!=0:
    Kahao_new_flag = 0
    Read_card_success_flag = 1
    if B_TX1_Busy:
        delay_ms(20)              // 等串口空闲
    B_TX1_Busy = 1
    Read_card_first_flag = 1      // 触发立即发送

    if Send_Manner == 0x55:       // 仅进站方向
        Read_card_100ms_flag = 1  // 触发 100ms 后二次发送

    SBUF = FirstLu_Kahao_buffer[0]  // 启动逐字节发送
    TX_DATA_NUM = 1
```

**关键：不等上位机轮询，检测到卡号变化立即上报告。** 发送通过 TI 中断逐字节完成。

### 1.8 卡号去重

同一张卡持续在范围内 → 每轮解码卡号与 `buffer2` 相同 → `Kahao_new_flag=0`，`Read_card_success_flag` 已为 1 → 条件 `(Read_card_success_flag==0 || Kahao_new_flag!=0)` 为 false → 不触发上报。

### 1.9 卡超时（200ms）

Timer0 10ms ISR 中：
```
if Read_card_success_flag != 0:
    Read_card_success_timer++
    if Read_card_success_timer >= 20:   // 200ms
        LED_GREEN = 1                   // 绿灯灭
        Read_card_success_flag = 0
```

### 1.10 进站 100ms 二次发送

Timer0 10ms ISR 中：
```
if Read_card_100ms_flag == 1:
    Read_card_100ms_timer++
    if Read_card_100ms_timer >= 10:     // 100ms
        Read_card_100ms_flag = 2         // 触发二次发送
        SBUF = FirstLu_Kahao_buffer2[0]  // 发送基准卡号
        TX_DATA_NUM = 1
        B_TX1_Busy = 1
```

二次发送在 TI 中断中逐字节完成，发送完毕后 `Read_card_100ms_flag=3`。

### 1.11 50ms 冷却

```
if Read_card_100ms_flag == 3:
    Read_card_100ms_timer++
    if Read_card_100ms_timer >= 5:      // 50ms
        Read_card_100ms_flag = 0         // 冷却结束，恢复指令响应
```

**仅进站方向有冷却期**（下放方向不设 `Read_card_100ms_flag=1`，因此也不进入 flag==3 的冷却逻辑）。

### 1.12 LED 行为

极简：上电红灯亮（`LED_RED=0`），绿灯灭（`LED_GREEN=1`）。校验通过有卡 → 绿灯亮（`LED_GREEN=0`）。200ms 无卡 → 绿灯灭。无模式切换闪烁、无红绿互斥逻辑、无黑卡处理。

## 二、被动行为（上位机指令触发）

### 2.1 通信参数

| 参数 | 值 |
|------|-----|
| 波特率 | 19200 bps |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 引脚 | P30 (TXD), P31 (RXD) |
| UART 模式 | Timer2 波特率发生器, 12T 模式 |

### 2.2 帧结构

**上位机 → 读卡器（3 字节）：**
```
[0] 0x10 | [1] 0xFF | [2] 命令字节
```

**读卡器 → 上位机：**
- 卡号包: 8 字节 `[0x10] [0xFF] [0x05] [Card3..7]`
- Fail 包: 7 字节 `[0x10] [0xFF] [0x04] ['F'] ['a'] ['i'] ['l']`

### 2.3 命令总览

| 命令 | 功能 | 方向切换 | 不忙时应答 |
|------|------|---------|-----------|
| 0x7A | 进站 | Send_Manner = 0x55 | 始终 Fail (7 字节) |
| 0x75 | 下放 | Send_Manner = 0xAA | 有卡报卡号 (8B) / 无卡报 Fail (7B) |

**不支持：** 0x9A/0x95（校验模式）、0x9D（连续模式）、0x90（版本查询）、0xA0 0x05（系统复位）。

### 2.4 命令接收（UART ISR）

RI 中断 → 3 字节状态机：

```
case 1: if RX1_Buffer[0] != 0x10 → RX1_Cnt=0 (帧头错误, 丢弃)
case 2: if RX1_Buffer[1] != 0xFF → RX1_Cnt=0
case 3:
    if   RX1_Buffer[2] == 0x7A → 进站处理
    elif RX1_Buffer[2] == 0x75 → 下放处理
    else → RX1_Cnt=0 (未知命令, 丢弃)
```

### 2.5 0x7A —— 进站

```
if Send_Manner != 0x55:
    Send_Manner = 0x55

if Read_card_100ms_flag != 0 || B_TX1_Busy != 0:
    静默忽略 (正在处理上报, 不应答)
else:
    B_TX1_Busy = 1
    Send_err_500ms_flag = 1
    SBUF = FirstLu_Send_ERR[0]    → 发送 7 字节 Fail 包
    TX_DATA_NUM = 1
```

### 2.6 0x75 —— 下放

```
if Send_Manner != 0xAA:
    Send_Manner = 0xAA

if Read_card_100ms_flag != 0 || B_TX1_Busy != 0:
    静默忽略
else:
    if Read_card_success_flag != 0:    // 有卡
        B_TX1_Busy = 1
        Send_card_500ms_flag = 1
        SBUF = FirstLu_Kahao_buffer[0] → 发送 8 字节卡号包
    else:                              // 无卡
        B_TX1_Busy = 1
        Send_err_500ms_flag = 1
        SBUF = FirstLu_Send_ERR[0]    → 发送 7 字节 Fail 包
    TX_DATA_NUM = 1
```

### 2.7 串口发送机制（TI 中断逐字节）

不同于第二代的 `LPUART_Transmit` 阻塞发送，第一代在 TI 中断中逐字节装载 SBUF：

```
TI 中断:
    if Read_card_first_flag == 1:
        uart_send_data(FirstLu_Kahao_buffer, 8)
        if TX_DATA_OVER: Read_card_first_flag=0; B_TX1_Busy=0

    if Read_card_100ms_flag == 2:
        uart_send_data(FirstLu_Kahao_buffer2, 8)
        if TX_DATA_OVER: Read_card_100ms_flag=3; B_TX1_Busy=0

    if Send_card_500ms_flag:
        uart_send_data(FirstLu_Kahao_buffer, 8)
        if TX_DATA_OVER: Send_card_500ms_flag=0; B_TX1_Busy=0

    if Send_err_500ms_flag:
        uart_send_data(FirstLu_Send_ERR, 7)
        if TX_DATA_OVER: Send_err_500ms_flag=0; B_TX1_Busy=0
```

`uart_send_data` 逐字节将缓冲区内容装入 SBUF，`TX_DATA_NUM` 索引递增。`TX_DATA_NUM >= data_len` 时置 `TX_DATA_OVER=1`，表示发送完成。

## 三、完整行为时序

### 3.1 衣架进站场景（Send_Manner = 0x55）

```
时刻 0:     衣架标签进入感应区
时刻 T:     解码完成, 校验通过 → LED_GREEN=0
时刻 T:     卡号与上次不同 → 立即发送 8 字节卡号包 (TI 中断逐字节)
时刻 T+100: Timer0 计数到 10, Read_card_100ms_flag=2
            二次发送同一卡号 (使用 FirstLu_Kahao_buffer2)
时刻 T+150: 二次发送完成, Read_card_100ms_flag=3
时刻 T+200: 冷却结束, Read_card_100ms_flag=0, 恢复指令响应

上位机在此期间发 0x7A:
  - T ~ T+200: Read_card_100ms_flag != 0 → 静默忽略
  - T+200 以后: 应答 7 字节 Fail (心跳确认)

上位机在此期间发 0x75:
  - T ~ T+200: Read_card_100ms_flag != 0 → 静默忽略
  - T+200 以后: Read_card_success_flag==1 → 应答 8 字节卡号

同一标签继续在范围内:
  - 每轮解码卡号与 buffer2 相同 → 不触发上报
  - 200ms 无新解码 → Read_card_success_flag=0, LED_GREEN=1

标签离开后:
  - 上位机发 0x7A → 应答 Fail
  - 上位机发 0x75 → 应答 Fail
```

### 3.2 衣架下放场景（Send_Manner = 0xAA）

```
时刻 0:     衣架标签进入感应区
时刻 T:     解码完成 → 立即发送 8 字节卡号包
            (下放方向: Read_card_100ms_flag 不置 1 → 无二次发送, 无冷却期)

上位机在此期间发 0x75:
  - T ~ T+send_time: B_TX1_Busy=1 → 静默忽略
  - 发送完成后: Read_card_success_flag==1 → 应答 8 字节卡号

上位机在此期间发 0x7A:
  - T ~ T+send_time: B_TX1_Busy=1 → 静默忽略
  - 发送完成后: 应答 7 字节 Fail
```

## 四、与第二代的差异总结

| 维度 | 第一代 (STC15) | 第二代 (HC32F002) |
|------|---------------|-------------------|
| 工作模式 | 仅模式 1 (无 mode 变量) | 模式 1 / 2 / 3 |
| 支持命令 | 0x7A, 0x75 | + 0x9A/0x95/0x9D/0x90/0xA0 0x05 |
| BCC 校验 | 无 | 模式 2 支持 |
| 连续模式 | 无 | 模式 3: 100ms/500ms 自主上报 |
| 校验关数 | 2 关 (行+列) | 5 关 (行+列+停止位+全零+脉宽范围) |
| LED | 简单: 红灯上电亮, 有卡绿灯亮 | 模式切换闪烁 / 红绿互斥 / 黑卡时序 |
| 系统节拍 | Timer0 10ms | ATIM3 ~50ms |
| UART 发送 | TI 中断逐字节 (SBUF) | LPUART_Transmit 阻塞 |
| 看门狗 | 无 (被注释) | IWDT ~106ms |
| Bootloader | 无 | 0x55 帧协议, Flash 分区 |
| 升级方式 | 物理 ISP 烧录 | 串口远程升级 |
| 代码规模 | 单文件 ~640 行 | 模块化 ~2000+ 行 |
| 主频 | 29.4912MHz, 12T | 48MHz, PCLK=6MHz |

## 五、与第二代兼容的基线行为

以下行为在第一代和第二代中**完全一致**，是重构第三代时必须保持的兼容性基线：

| # | 行为 | 说明 |
|---|------|------|
| 1 | `0x10 0xFF` 帧头 + 3 字节命令帧 | 格式一致 |
| 2 | 0x7A → 进站方向 (0x55) + 应答 Fail | 语义一致 |
| 3 | 0x75 → 下放方向 (0xAA) + 有卡报卡号 / 无卡报 Fail | 语义一致 |
| 4 | 8 字节卡号包: `0x10 0xFF 0x05` + 5 字节卡号 | 格式一致 |
| 5 | 7 字节 Fail 包: `0x10 0xFF 0x04` + "Fail" | 格式一致 |
| 6 | 卡号变化立即上报（不等轮询） | 逻辑一致 |
| 7 | 进站 100ms 二次上报 | 逻辑一致, 计数方式不同 |
| 8 | 下放单次上报 | 逻辑一致 |
| 9 | 进站 50ms 冷却 + 冷却期忽略指令 | 逻辑一致 |
| 10 | `B_TX1_Busy` / `Read_card_100ms_flag` 忙保护 | 逻辑一致 |
| 11 | 同一卡号去重（比较 buffer2） | 逻辑一致 |
| 12 | 200ms 无新卡 → 超时清零 | 逻辑一致, 计数方式不同 |
| 13 | `Send_Manner` 方向状态 (0x55/0xAA) | 一致 |
| 14 | SHD 初始化: 高 50ms → 低 | 时序一致 |
| 15 | 125kHz 载波通过定时器硬件产生 | 机制一致 |
| 16 | 曼彻斯特解码: 脉宽分类 + 64 位还原 | 算法一致 |
| 17 | 行校验 + 列校验逻辑 | 算法一致 |
| 18 | 卡号提取: 40 位 → 5 字节 (大端) | 算法一致 |
| 19 | 19200-8-N-1 串口参数 | 一致 |

**向后兼容的保证：** 如果上位机仅使用 0x7A 和 0x75 轮询，第一代和第二代读卡器可互相替换，上层业务逻辑无需任何修改。
