## 2. 解码状态机

```mermaid
stateDiagram-v2
    [*] --> SEEK_PREAMBLE

    state SEEK_PREAMBLE {
        [*] --> 扫描边沿
        扫描边沿 --> 分类间隔 : 收到 edge
        分类间隔 --> 检查交替 : is SHORT
        分类间隔 --> 重置计数 : not SHORT
        检查交替 --> 累加计数 : 方向交替
        检查交替 --> 重置计数 : 同方向
        累加计数 --> 锁定 : short_cnt ≥ 14
    }

    state RECEIVE {
        逐位解码 --> SHORT分支 : interval = SHORT
        逐位解码 --> LONG分支 : interval = LONG
        逐位解码 --> 碎片跳过 : interval = DEBRIS
        逐位解码 --> 超时重置 : interval = TIMEOUT

        SHORT分支 --> 得1bit : need_skip = 0 (中间跳变)
        SHORT分支 --> 丢弃 : need_skip = 1 (位边界)
        LONG分支 --> 复制上一位
    }

    得1bit --> 检查收满 : bit_idx++
    丢弃 --> 检查收满
    复制上一位 --> 检查收满
    检查收满 --> VERIFY : bit_idx ≥ 64
    检查收满 --> 逐位解码 : 继续收

    SEEK_PREAMBLE --> RECEIVE : 锁定成功 · 计算 avg_short
    RECEIVE --> SEEK_PREAMBLE : TIMEOUT 或 err > 3

    state VERIFY {
        [*] --> 同步头校验 : bits[0..8] ≥ 7 个 1?
        同步头校验 --> 行校验 : 通过
        同步头校验 --> 失败 : 失败
        行校验 --> 列校验 : 10行偶校验全过
        行校验 --> 失败 : 失败
        列校验 --> 停止位 : 4列偶校验全过
        列校验 --> 失败 : 失败
        停止位 --> 提取ID : bit[63] == 0
        停止位 --> 失败 : 失败
    }

    VERIFY --> 帧投票 : 校验通过
    VERIFY --> SEEK_PREAMBLE : 校验失败

    帧投票 --> 输出卡号 : 连续 2 帧 ID 一致
    帧投票 --> SEEK_PREAMBLE : 帧不一致

    输出卡号 --> SEEK_PREAMBLE
```

> 详细算法见 [[EM4095详解]] 第三章。

## 3. 应用层状态机

```mermaid
stateDiagram-v2
    [*] --> INIT

    INIT --> IDLE : 外设初始化完成

    IDLE --> READING : 收到 SCAN 指令
    IDLE --> READING : 自动轮询模式 (AUTO=1)

    READING --> REPORTING : 卡号就绪 (on_id 回调)
    READING --> IDLE : 超时 / 未检测到卡
    READING --> IDLE : AT+CANCEL

    REPORTING --> IDLE : 上报完成 · TX FIFO 排空
    REPORTING --> READING : 自动上报模式 (不等指令)

    note right of READING
        em4095_poll() 持续消费 edge_fifo
        解码 + 校验 + 投票 在 poll 内完成
    end note
```

### 串口协议 (AT 指令集)

| 指令              | 响应                                     | 说明     |
| --------------- | -------------------------------------- | ------ |
| `AT\r\n`        | `OK\r\n`                               | 心跳测试   |
| `AT+SCAN\r\n`   | `+CARD:XXXXXXXXXX\r\n` 或 `+NOCARD\r\n` | 单次读卡   |
| `AT+AUTO=1\r\n` | `OK\r\n`                               | 开启自动上报 |
| `AT+AUTO=0\r\n` | `OK\r\n`                               | 关闭自动上报 |
| `AT+CANCEL\r\n` | `OK\r\n`                               | 中止当前读卡 |
| `AT+VER\r\n`    | `+VER:SR3-1.0\r\n`                     | 固件版本   |

## 5. 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 采集方案 | 方案② Input Capture | ISR 仅 ~3.9kHz，硬件锁存精度 ±1µs，CPU 负载极低 |
| 边沿 FIFO | 复用 `SPSC_FIFO` | 与 UART FIFO 统一基础设施，已通过评审加固 |
| 解码位置 | 全部放主循环 | ISR 不放判断逻辑，classify/decode/verify/vote 全在主循环 |
| 串口协议 | AT 指令文本帧 | 调试友好，`\r\n` 分隔，兼容任意串口工具 |
| 帧投票 | 连续 2 帧一致即输出 | 平衡响应速度与可靠性 (EM4100 每 32ms 一帧) |
| 校验策略 | 同步头≥7/9 + 10行 + 4列 + 停止位 | 双重偶校验，随机序列误判概率 ≈ 1/32768 |

## 6. 核心数据流时序

```mermaid
sequenceDiagram
    participant EM4095 as EM4095
    participant ISR as ATim3_IRQHandler
    participant FIFO as edge_fifo
    participant DEC as em4095_core
    participant APP as main loop
    participant UART as Host

    EM4095->>ISR: 双边沿捕获中断
    ISR->>ISR: 读 CCR, 算 interval
    ISR->>FIFO: 写 {level, interval}

    loop 主循环轮询
        APP->>FIFO: em4095_poll() 取边沿
        FIFO->>DEC: process_edge()
        DEC->>DEC: SEEK → RECEIVE → VERIFY
    end

    DEC->>APP: on_id(id[5])
    APP->>APP: vote_and_output()
    APP->>UART: +CARD:XXXXXXXXXX\r\n
```

| 参数 | 值 |
|------|------|
| EM4100 帧周期 | ~32.8ms (64 bits × 512µs) |
| 帧间隔 | 32~35ms |
| 中断频率 (方案②) | ~3.9kHz (每边沿一次) |
| ISR 执行时间 | < 2µs @48MHz |
| 解码延迟 (2帧投票) | ~66ms (锁定 + 2帧) |
| 最坏响应时间 | ~100ms (含锁相搜索) |
| UART TX 一帧 | ~5.7ms (14 字节 × 10bit ÷ 19200bps) |
