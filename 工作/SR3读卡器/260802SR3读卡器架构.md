## 2. ISR ↔ 主循环上下文边界

```mermaid
flowchart LR
    subgraph isr_ctx["ISR 上下文 (高优先级)"]
        direction TB
        ISR_UART["LpUart1_IRQHandler<br/>─────────<br/>RX: 读 DR → 写 g_rxFifo<br/>TX: 读 g_txFifo → 写 DR"]
        ISR_EM["ATim3_IRQHandler<br/>─────────<br/>读 CCR → 算 interval<br/>→ 写 edge_fifo"]
        ISR_TICK["SysTick_Handler<br/>─────────<br/>s_u32Ms++"]
    end

    subgraph main_ctx["主循环上下文"]
        direction TB
        POLL_EM["em4095_poll()<br/>消费 edge_fifo<br/>→ process_edge()"]
        POLL_UART["Bsp_UartRead()<br/>消费 g_rxFifo"]
        APP["应用逻辑<br/>指令解析 + 状态机 + 上报"]
    end

    subgraph fifos["SPSC FIFO 隔离层"]
        F1["g_rxFifo<br/>256B, ISR写→主循环读"]
        F2["g_txFifo<br/>256B, 主循环写→ISR读"]
        F3["edge_fifo<br/>128条, ISR写→主循环读"]
    end

    ISR_UART -->|"spsc_fifo_write"| F1
    F1 -->|"spsc_fifo_read_bulk"| POLL_UART
    APP -->|"spsc_fifo_write_bulk"| F2
    F2 -->|"spsc_fifo_read"| ISR_UART
    ISR_EM -->|"写 {level, interval}"| F3
    F3 -->|"主循环消费"| POLL_EM

    POLL_UART --> APP
    POLL_EM --> APP
    APP -->|"Bsp_UartWrite"| F2
```

**关键约束：**
- ISR 只写 FIFO、只做最小运算（读寄存器、算差值、push），不做任何解码/校验。
- 主循环只读 FIFO，所有算法（classify / process_edge / verify / vote）在主循环完成。
- 通过 SPSC FIFO 解耦，**零中断屏蔽、零临界区**。

## 3. 解码状态机

```mermaid
stateDiagram-v2
    [*] --> SEEK_PREAMBLE

    state SEEK_PREAMBLE {
        [*] --> 扫描边沿
        扫描边沿 --> 分类间隔 : 收到 edge
        分类间隔 --> 检查交替 : is SHORT
        分类间隔 --> 重置计数 : not SHORT
        检查交替 --> 累加计数 : 方向交替
        检查交替 --> 重置计数 : 同方向
        累加计数 --> 锁定相位 : short_cnt ≥ 14
        锁定相位 --> RECEIVE_ENTRY : 计算 avg_short<br/>need_skip = short_cnt & 1
    }

    RECEIVE_ENTRY --> RECEIVE

    state RECEIVE {
        逐位解码 --> SHORT分支 : interval = SHORT
        逐位解码 --> LONG分支 : interval = LONG
        逐位解码 --> 碎片跳过 : interval = DEBRIS
        逐位解码 --> 超时重置 : interval = TIMEOUT

        SHORT分支 --> 得1bit : need_skip=0<br/>(中间跳变)
        SHORT分支 --> 丢弃 : need_skip=1<br/>(位边界)

        LONG分支 --> 复制上一位 : need_skip=0
    }

    得1bit --> 检查收满 : bit_idx++
    丢弃 --> 检查收满
    复制上一位 --> 检查收满
    检查收满 --> VERIFY : bit_idx ≥ 64
    检查收满 --> 逐位解码 : 继续收

    SEEK_PREAMBLE --> RECEIVE_ENTRY : 锁定

    RECEIVE --> SEEK_PREAMBLE : TIMEOUT 或 err > 3

    state VERIFY {
        校验开始 --> 同步头校验 : bits[0..8] ≥ 7 个 1?
        同步头校验 --> 行校验 : 通过
        同步头校验 --> 失败 : 失败
        行校验 --> 列校验 : 10行偶校验全过
        行校验 --> 失败 : 失败
        列校验 --> 停止位 : 4列偶校验全过
        列校验 --> 失败 : 失败
        停止位 --> 提取ID : bit[63] == 0
        停止位 --> 失败 : 失败
    }

    VERIFY --> 帧投票 : 校验通过
    VERIFY --> SEEK_PREAMBLE : 校验失败

    帧投票 --> 输出卡号 : 连续 2 帧 ID 一致
    帧投票 --> SEEK_PREAMBLE : 帧不一致

    输出卡号 --> SEEK_PREAMBLE
```

> 详细算法见 [[EM4095详解]] 第三章。

## 4. 应用层状态机

```mermaid
stateDiagram-v2
    [*] --> INIT

    INIT --> IDLE : 外设初始化完成

    state IDLE {
        [*] --> 等待指令
        等待指令 --> 解析指令 : 收到完整帧
    }

    IDLE --> READING : READ 指令 / 自动轮询
    IDLE --> IDLE : 未知指令 → 回错误

    state READING {
        [*] --> 使能EM4095
        使能EM4095 --> 轮询解码 : start()
        轮询解码 --> 轮询解码 : em4095_poll()
        轮询解码 --> 拿到卡号 : on_id() 回调
        轮询解码 --> 超时 : 超过 N ms 无卡
    }

    READING --> REPORTING : 卡号就绪
    READING --> IDLE : 超时 / 取消

    REPORTING --> IDLE : 上报完成 (TX FIFO 排空)

    note right of READING
        自动上报模式:
        REPORTING → READING (不等指令)
    end note
```

### 串口协议 (AT 指令集)

| 指令 | 响应 | 说明 |
|------|------|------|
| `AT\r\n` | `OK\r\n` | 心跳测试 |
| `AT+SCAN\r\n` | `+CARD:XXXXXXXXXX\r\n` 或 `+NOCARD\r\n` | 单次读卡 |
| `AT+AUTO=1\r\n` | `OK\r\n` | 开启自动上报，卡靠近即发 `+CARD:...` |
| `AT+AUTO=0\r\n` | `OK\r\n` | 关闭自动上报 |
| `AT+VER\r\n` | `+VER:SR3-1.0\r\n` | 固件版本 |

## 6. 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 采集方案 | 方案② Input Capture | ISR 仅 ~3.9kHz，硬件锁存精度 ±1µs，CPU 负载极低 |
| 边沿 FIFO | 复用 `SPSC_FIFO` | 与 UART FIFO 统一基础设施，已通过评审加固 |
| 解码位置 | 全部放主循环 | ISR 不放判断逻辑，分类/解码/校验/投票全在主循环 |
| 串口协议 | AT 指令文本帧 | 调试友好，`\r\n` 分隔，兼容串口助手 |
| 帧投票 | 连续 2 帧一致即输出 | 平衡响应速度与可靠性（EM4100 每 32ms 一帧） |
| 校验策略 | 同步头≥7/9 + 10行 + 4列 + 停止位 | 双重偶校验，随机序列误判概率 ≈ 1/32768 |

## 7. 核心数据流时序

```mermaid
sequenceDiagram
    participant EM4095 as EM4095
    participant ISR as ATim3_IRQHandler
    participant FIFO as edge_fifo
    participant DEC as em4095_core
    participant APP as main loop
    participant UART as Host

    EM4095->>ISR: 双边沿捕获中断
    ISR->>ISR: 读 CCR, 算 interval
    ISR->>FIFO: 写 {level, interval}

    loop 主循环轮询
        APP->>FIFO: em4095_poll() 取边沿
        FIFO->>DEC: process_edge()
        DEC->>DEC: SEEK → RECEIVE → VERIFY
    end

    DEC->>APP: on_id(id[5])
    APP->>APP: vote_and_output()
    APP->>UART: +CARD:XXXXXXXXXX\r\n
```

### 时序参数

| 参数 | 值 |
|------|------|
| EM4100 帧周期 | ~32.8ms (64 bits × 512µs) |
| 帧间隔 | 32~35ms |
| 中断频率 (方案②) | ~3.9kHz (每边沿一次) |
| ISR 执行时间 | < 2µs @48MHz |
| 解码延迟 (2帧投票) | ~66ms (锁定 + 2帧) |
| 最坏响应时间 | ~100ms (含锁相搜索时间) |
| UART TX 一帧 | ~5.7ms (14 字节 × 10bit ÷ 19200bps) |
