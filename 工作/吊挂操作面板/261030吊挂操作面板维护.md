## 2. 契约

- **架构**：本文件以面板（HC32F460KETA）为主；面板经 UART 命令协议连控制器（GD32F470ZI），控制器再经以太网 UDP 连上位机 / 其它控制器、经 CANopen 连电机节点（拓扑图见归档附录 A）。控制器细节见 [[261029S3维护]]。
- **面板协议**：BCC 校验；单包上限 129 字节（`EVERY_PACK_MAX`），命令缓冲 5 包；重发 450ms、最多 2 次（`CmdProtocol.h`）。
- **控制器 UDP（边界）**：结构体按 `#pragma pack(1)` 打包（`UDP_CMD.h`）；PC 心跳含 MAC、进站满、允许接收、链条启动、语言、屏蔽、返工模式。
- **版本标识**：面板用 `MenuUI.h` 的 `CPVER`（当前检出 `E10`；`develop` 为 `060`、`release/V061` 为 `R61`）；控制器用 `APP/UDP_Comu.c` 的 `ControlVer`（`develop` 为 `V3.0.07.0`，`人体感应定制/develop` 为 `V3.e.07.1`）。
- **报废 `0x0106`**：`func 0x00` 查询衣架（E10 起进页前不再发）；`func 0x03` 已由 0x04 取代、面板不再发送（`80db7ce`）；`func 0x04` 执行 payload 13 字节 = 10 字节 ASCII 卡号 + `,` + 2 字节 ASCII 件数（`01`–`99`，`00` 非法）；0x04 不等 `0x0106` ACK，只等 `0x1002` 的 0x82 提示消息或 `IsWaitSign` 超时。
- **`0x0106` 状态位**：`OpStaOrCnt` 低 7 位 0=浏览 / 输入、1=翻页等待、2=0x04 等待，高位 `0x80`=收到回复；页响应只在 state 1 置位并留页，0x82 只在 state 2 置位后回主页。
- **报废页翻页**：已废止（← C13，E10 `8bb846e` 注释下线）；恢复时用 `func 0x02` / `func 0x01` + 1 字节 `u8PS` 页请求，细节见归档 R4 段。
- **读卡器版本 `0x149`（← C3）**：`0x148` 为控制器版本、`0x150` 为防晃；请求 1 字节 `reader_sel`（0=进站，1/2 预留下放 / 出站）；响应 `[reader_sel, status, ver10]`，status 0=OK / 1=超时或失联，`ver10` = 读卡器应答的 6 字节 ASCII 版本（`RD03xx`，当前基线 `RD0313`）补 0 到 10 字节；控制器发 `10 A0 01`、解析 `10 A1 01` 应答帧（10 字节 = 3 头 + 6 版本 + MODE），500ms 超时；面板 About 页显示，上位机后续复用同一缓存。
- **换绑 `0x112`（← C8）**：请求 `0x112` + `0xAA` 开 / `0x55` 关（经 `0x85` 透传，1 字节）；任意回复只清等待、用于判超时，不读回复数据、不显示弹窗；开关仍由 0x1001 心跳 byte39 同步。实现只在 `feature/换绑优化`（`e82dcaa`），未合入 develop 与 E10 线。

## 3. 方案

### 3.1 面板读卡器版本查询（R2）

- **链路**：面板 About 页 → 控制器 `OBJ_READER_VER 0x149` → 该站进站读卡器 `10 A0 01` → `10 A1 01 "RD0313" MODE` → 控制器缓存 → 面板显示。
- **对象语义**：请求 1 字节 `reader_sel`；响应 `[reader_sel, status, ver10]`；读卡器实际应答 6 字节 ASCII 版本 + MODE，对象内补 0 到 10 字节。
- **控制器**：`RFID_Recv` 增加 `10 A1 01` 应答解析（10 字节帧），缓存到 `ReaderVer[sNUM][11]`；查询超时 500ms；`Panel_ReadData` 触发查询，`Panel_Send` 异步回 `0x149`。
- **面板**：About 页新增 `Reader:` 行（y=63）；进入页面发 `0x0149`（sel=0）；解析后显示 `RD0313`，超时 / 失联显示 `--`；CP / 控制器版本逻辑不变；阿拉伯语分支按镜像布局同样加该行。
- **不做**：不改读卡器固件 / SR3 协议 / 上位机；暂不查下放 / 出站读卡器（selector 预留）；不改换绑逻辑。
- **参考**：[[260206测试程序增加读卡器版本号]]（历史测试程序记录，含三种读卡器种类识别；不是当前生产面板实现）；读卡器 `0x10` 指令表见 [[260804SR3框架整理]]。

```mermaid
sequenceDiagram
    participant P as 面板
    participant C as 控制器
    participant R as 进站读卡器
    P->>C: 0x0149 (reader_sel=0)
    C->>R: 10 A0 01
    R-->>C: 10 A1 01 "RD0313" MODE
    C-->>P: 0x0149 [sel,status,ver10]
    alt status=0
        P->>P: 显示 RD0313
    else 超时 / 失联
        P->>P: 显示 --
    end
```
