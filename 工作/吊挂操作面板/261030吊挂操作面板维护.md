## 2. 契约

- **架构**：本文件以面板（HC32F460KETA）为主；面板经 UART 命令协议连控制器（GD32F470ZI），控制器再经以太网 UDP 连上位机 / 其它控制器、经 CANopen 连电机节点；控制器细节见 [[261029S3维护]]
- **协议 / 数据格式**：
  - 面板协议：BCC 校验；单包上限 129 字节（`EVERY_PACK_MAX`），命令缓冲 5 包；重发 450ms、最多 2 次（`CmdProtocol.h`）
  - 控制器 UDP（边界）：结构体按 `#pragma pack(1)` 打包（`UDP_CMD.h`）；PC 心跳含 MAC、进站满、允许接收、链条启动、语言、屏蔽、返工模式
  - 版本：面板 `develop` 为 `CP060`、`release/V061` 为 `R61`；控制器 `V3.0.07.0`
- **换绑协议 v1.2（← C1/C2/C8/C9，2026-11-02/09）**：`0x1001` 心跳追加 `ReBindEnable` 于负载偏移 39（0xAA 开 / 0x55 关，控制器直传 PC 心跳第 31 字节原值；面板归一化 0xAA→1）；面板 `u16PLen >= 50`（负载 ≥40）判存在；旧 38/39 字节帧走旧“扫码自动出衣”逻辑。透传使用 raw 子对象 `0x0112`（协议 V1.26 已新增 `112H 启动换绑`：W、1 字节、0x55 关闭 / 0xAA 开启；Ack 0x01 允许 / 0x00 拒绝；`111H` 已用于“带类型返工”），必须封装在 `0x0151` 内（禁止直发；控制器主对象 `0x112` 为 `OBJ_READER_EN`，`0x111` 为 `OBJ_RAISE_TIMEOUT2`）；控制器经 UDP `CMD3=0xB4` 上送、PC 以 `CMD3=6` 下送；450ms 首发 + 700ms×2 重试，约 1.85s 超时；实现分支 `feature/换绑优化`
- **换绑生效源（← C2）**：Ack `0x01` / `0x00` 只用于停止重发；`PCustomOCTb[4]` 只由 0x1001 `ReBindEnable` 更新；心跳边沿才持久化；ACK 不直接写状态
- **QCPass 键行为（← C10/C11）**：与手拍逐行一致，唯一差异是直发指令（手拍 `0x021C`／QCPass `0x0218`）；`PCustomOCTb[4]==1 && BondHanger!=0` 时未扫码 → `TNeedScanBar`、已扫码 → `0x0107`（衣架号＋扫码内容，同手拍格式）；其余情况直发 `0x0218`；无 `ReBindSupported` 门控（C11）
- **照明输出分离（← C12/R3）**：照明与输出独立双通道，各一 RAM 手动接管标志；手动优先，接管期跳过自动；登录边沿释放；状态不同步；手动命令 `0x195`（照明）/`0x196`（输出），值 1=手动开/2=手动关/0=回自动（面板只发 1/2，0 由控制器登录释放）
- **分离启用门控（← C15，C13/C14 作废）**：门控信号=心跳 byte39（`HumanSensValid`，控制器按端口有无配置判定 0/1，T3-2 内定，只看输入端口（InPinID!=0 即=1，输出不管；C16 用户拍板）；面板按负载 `>=40` 解析 `u8DataBuf[39]`（缺段清零；`554e625` 的 `[40]/>=41` 由 T3-4 对齐），`key.c` 以此分流（0 走老开关灯 `0x021E`，非零发手动命令）；控制器负载 40 字节（现行 39＋1：`[39]` 门控值）
- **读卡器版本对象（← C3，2026-11-02）**：新增 `OBJ_READER_VER 0x149`（`0x148` 为控制器版本，`0x150` 为防晃）；请求 1 字节 `reader_sel`（0=进站，1/2 预留下放/出站）；响应 `[reader_sel, status, ver10]`，status 0=OK / 1=超时或失联；控制器向进站读卡器发 `10 A0 01`，解析 `10 A1 01`，500ms 超时；面板 About 页显示，上位机后续复用同一缓存
- **构建与测试命令**：见 §0 基线；无自动化测试

### 3.2 换绑开关方案（R1）

- **字段存在性即开关**：不判断版本号、不判断 S3；`0x1001` 负载长度 ≥ 40 字节（`u16PLen >= 50`）视为存在 `ReBindEnable`，否则按旧“扫码自动出衣”逻辑。
- **状态分工（← C4）**：`PCustomOCTb[4]` 为生效值（心跳驱动），存 `GlobalProfile[S_CodeAutoOut][0]`，默认 0；`PCustomOCShow[4]` 为编辑值（F1 装载、OK 只发请求）；复用透传层共享状态（`m_TransCmdResend` + `PackSign[U_ReBind]`，`U_ReBind=18`），无单独 pending/重试变量与 ACK/重发函数；`PCustomTb[4]` 仅 ☒/☑ 字形。
- **心跳为生效源**：KEY_OK 不直接赋值，直接调 `send_trans_command_start(0x85, 0x100 + U_ReBind, …)` 发送目标值（封装在 0x0151 内）；`PCustomOCTb[4]` 只由 0x1001 `ReBindEnable` 边沿更新；心跳值变化时持久化一次；透传层 `AckRightSign` / `IsWaitSign` 停止重发。
- **应答只作重发依据**：Ack `0x01` 允许 / `0x00` 拒绝都只停止重发，不写 `PCustomOCTb[4]`；无 Ack 按 450ms 首发 + 700ms×2 重试，约 1.85s 后清 pending 并提示“未响应”；拒绝只提示“不允许”，生效值仍以心跳为准。
- **时序**：Ack 与心跳到达顺序任意；ACK 处理器不碰生效值，心跳处理器不依赖 ACK；避免 ACK 覆盖心跳或反之。
- **兼容（← C4）**：菜单文案统一为“启动换绑”（15 语言 `MCustomTb[4]` 原项直改）；字段不存在时仅 OK 保留旧赋值逻辑，不再区分旧文案；拒绝弹 `TReBindDenied=62`“不允许启用换绑”，无 ACK 超时按 `IsWaitSign==2` 弹 `TNoAck`（与其它菜单一致）。
- **约束**：V-1 必须基于含 `QCFailMode` 的控制器 `develop`，否则 `ReBindEnable` 会落到偏移 38；禁止复用 `STABindMode` bit12（控制器该位为 `canError`）；协议 V1.26 已新增 `112H 启动换绑`（W，1 字节，0x55 关闭 / 0xAA 开启 ← C9；Ack 0x01 允许 / 0x00 拒绝），`111H` 已用于“带类型返工”（C1）。
- **遗留（待 T1-4 / V-1 验收）**：上位机透传允许 / 拒绝真实现；旧 `S_CodeAutoOut=1` 升级迁移；断链 / 双面板是否一律以 0x1001 为准。
- **不做**：不改控制器 / 上位机；不改 0x0107 绑定数据格式；不改非标准版。

```mermaid
sequenceDiagram
    participant P as 面板
    participant C as 控制器
    participant PC as 上位机
    P->>C: raw 0x0112 (目标值 0/1)
    C->>PC: 0x0151 / UDP 0xB4
    PC-->>C: CMD3=6 (0x01 允许 / 0x00 拒绝)
    C-->>P: ACK (只停止重发)
    C-->>P: 0x1001 ReBindEnable (生效源)
    alt 心跳值变化
        P->>P: 更新 PCustomOCTb[4] + 持久化
    else 心跳未变
        P->>P: 保持原值；拒绝提示“不允许”
    end
```

- **时序约束（← C2）**：ACK 与心跳顺序任意；ACK 不写 `PCustomOCTb[4]`，只停止重发。

### 3.3 面板读卡器版本查询（R2）

- **链路**：面板 About 页 → 控制器 `OBJ_READER_VER 0x149` → 该站进站读卡器 `10 A0 01` → `10 A1 01 "RD0312" MODE` → 控制器缓存 → 面板显示。
- **对象语义（← C3）**：请求 1 字节 `reader_sel`（0=进站；1/2 预留下放/出站）；响应 `[reader_sel, status, ver10]`，status 0=OK / 1=超时或失联；版本字符串 10 字节，不足补 0。
- **控制器**：`RFID_Recv` 增加 `10 A1 01` 10 字节响应解析，缓存到 `ReaderVer[sNUM][11]`；查询超时 500ms；`Panel_ReadData` 触发查询，`Panel_Send` 异步回 `0x149`。
- **面板**：About 页新增 `Reader:` 行（y=63）；进入页面发 `0x0149`（sel=0）；解析响应后显示 `RD0312`，超时 / 失联显示 `--`；CP / 控制器版本逻辑不变。
- **不做**：不改读卡器固件 / SR3 协议 / 上位机；暂不查下放 / 出站读卡器（selector 预留）；不改 R1 换绑逻辑。

```mermaid

    participant C as 控制器

    P->>C: 0x0149 (reader_sel=0)
    C->>R: 10 A0 01
    R-->>C: 10 A1 01 "RD0312" MODE
    C-->>P: 0x0149 [sel,status,ver10]
    alt status=0

    else 超时 / 失联
```

### 3.4 控制器换绑链路、面板归一化与 QCPass 键判断（R1，←C5/C6/C7/C8/C9/C10/C11）

### 3.5 照明输出分离控制（R3，←C12）

- **通道独立（D10）**：照明（`Lamp`）与输出（`OUT_IO`）各一手动接管标志（RAM，不进 Flash）；接管期间 `BodySensFunc` 跳过该通道自动逻辑；两通道互不联动。

- **手动命令对象（已定）**：`0x195`（照明手动）/`0x196`（输出手动），值语义 0=回自动 / 1=手动开 / 2=手动关（面板只发 1/2；控制器 `Panel.c` 落对象处理，走现有命令协议，不新增协议栈）。
- **释放（T3-2，方案 B）**：控制器检测 `StatParam[].LoginState` 边沿变化（NoLogin/LoginOK/Logining 之间任意跃迁）即清双通道接管，回落人体自动；登录状态源已核实（`UDP_CMD.c:283 LoginCmd` / `UDP_Comu.c:478/488` 登出 / 刷卡登录维护）。
- **启用门控（← C15，C13/C14 作废）**：门控信号=心跳 byte39（`HumanSensValid`，0/1）。面板（`554e625` 为 byte40 实现，由 T3-4 对齐到 39）：`MAIN.C` 按负载 `>=40` 解析 `u8DataBuf[39]`（缺段/短帧清零），`key.c` 照明键以此分流（0→老开关灯 `0x021E` 原样，含 `LightSign/0x0106` 应答；非零→`0x195/0x196` 本地交替 1/2）；`PIOinSetTb[40]/PIOoutSetTb[33]` 初值 `00`=未配置。
- **控制器上报（T3-2 范围，分支 `feature/人体存在`）**：`Panel.h` 的 `PER_UPLOAD_PACK_STRU`（现 39 字节，`Language@36/StopOut@37/QCFailMode@38`）追加 1 字节 `[39]=HumanSensValid` 至 40（`Len=tempLen+10` 自动变 50）；`Panel.c` 的 `PerUploadPack` 按 `BodySens[StatNum]` 端口配置赋值（只看输入端口（C16 已定），任务内定）；`InPinID/OutPinID` 配置链路（`0x190/0x191`＋Flash）已存在，零改动。
- **控制器手动接管（T3-2 范围）**：`BodySens` 拆照明/输出两 RAM 接管标志；`BodySensFunc` 接管通道跳过自动（输出关延时重计时语义保留）；`0x195/0x196` 对象处理（参照 `OBJ_BODY_SENS_IN/OUT` 的 `InPinConfig/OutPinConfig` 分支位置，`Panel.c` 落 `case`，值 1=手动开/2=手动关/0=回自动）；登录边沿释放（推荐 `BodySensFunc` 内缓存上轮 `LoginState` 比对，任意跃迁即清双通道接管，不跨模块钩子）；登录开灯/退出关灯加 `InPinID==0` 门控（C17：有配置则不碰灯，退出关灯不再打乱自动机 `State`；未配置走老路）。
- **前置**：面板分支已含门控实现（`554e625`）；控制器分支基线即 `develop` @`aeef0ca`，但当前检出不在该分支，开工先 `switch feature/人体存在` 并核对。
- **启用门控（← C13，作废，被上 C14 条取代）**：延时值门控已废弃。
