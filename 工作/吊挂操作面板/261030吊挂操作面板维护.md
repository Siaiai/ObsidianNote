## 2. 契约

- **架构**：面板（HC32F460KETA）经 UART 命令协议连控制器（GD32F470ZI）；控制器经以太网 UDP 连上位机 / 其它控制器；经 CANopen 连电机节点；两仓库均无 README / AGENTS，代码为唯一事实源
- **协议 / 数据格式**：
  - 面板协议：BCC 校验；单包上限 129 字节（`EVERY_PACK_MAX`），命令缓冲 5 包；重发 450ms、最多 2 次（`CmdProtocol.h`）
  - 控制器 UDP：结构体按 `#pragma pack(1)` 打包（`UDP_CMD.h`）；PC 心跳含 MAC、进站满、允许接收、链条启动、语言、屏蔽、返工模式
  - 版本：控制器 `V3.0.06.3`；面板 `CP060`（`V-CP060260528`）
- **构建与测试命令**：见 §0 基线；无自动化测试
