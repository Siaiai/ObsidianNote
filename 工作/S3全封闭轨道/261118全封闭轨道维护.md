## 2. 契约 v1（2026-11-19 定稿）

- 帧格式沿用 `0xFA CMD1 CMD2 CMD3 LineNo StatNo LenHi LenLo Data`；空推杆上报用**新码 `0xC2`**（`CMD2=0x01`），`Len=1`、`Data[0]` = 主轨杆号 `NowPoleNum`，站号走帧头 `StatNo`
- 不复用标准线 `0xC1`：它的语义是「避让光电触发＝有衣架」，与本需求相反（← D1）
- 首发时机：出站时机点之前；重发允许跨过出站时机点（出站后该推杆已离开，但保留补齐上报）
- 空推杆判定：复用现有推杆占有模型 `InToOutPoleFlag[站][k] == POLE_NO_HANGER`（`0x55`）；避让光电触发一律记为该推杆有衣架（`0xAA`）
- 重发：首发 + 2 次重发（共 3 帧），超时 **200ms**，即 `t0`、`t0+200ms`、`t0+400ms`；收到上位机应答即停；3 帧后仍无应答静默丢弃，不报故障
- 无分站开关，全站生效
- 杆号来源唯一：`StatParam[].NowPoleNum`，由主轨光电驱动刷新；不得另建杆号
- 避让光电安装约束（现场调参定稿）：离出站口约 1000mm、固定位置误差 ≤2cm，最小距离 ≥ `S_出/速比 + 0.25m + 0.05m`；与避让读卡器重叠时 1300mm；站间距 ≥1800mm。上报时刻由光电物理位置与主轨速度决定，固件不做距离补偿
- 版本号：全封闭 v2 线改动必须递增 `ControlVer`（当前 V3.3.05.8）

## 3. 方案

需求与参数均已定稿（← D1），实现按此走：

- **窗口**：`UDP_CMD.c MainRailPD_Deal` 处理新杆值时（`InToOutPoleFlag[]` 移位之后）为该站启动「空推杆窗口」，长度按 `OutValve[站].DlyPole` 杆计。
- **判定与首发**：在窗口末端、出站动作（`MotionUnit.c MotionOut` 的 `sIDLE` 分支）之前判定该站对应槽位是否为 `POLE_NO_HANGER`；是则立刻发 `0xC2`（杆号取 `StatParam.NowPoleNum`），并记下已报杆号。
- **重发**：每站一个小状态机（`TC` + 已发次数 + 已报杆号）。`t0` 发首发，`t0+200ms`、`t0+400ms` 各重发一次；收到应答或杆号变化立即清状态；3 帧后放弃，静默。**注意**：现场余量只有约 120ms 时，第 2、3 帧会落在出站时机点之后，上位机需按杆号去重并自行判断该杆是否还有效。
- **发送位置**：`Pc_UDPSend` 按站轮询，沿用现有 `Command_Data` + `Command_Num` 排队，每轮只发一帧，不抢占其它上报。
- **不复用 `AvoidPDBan`**：标准线的 `Ban` 是「上位机确认后本杆别再报」，本需求是「报给上位机由它决定」，两者不共用。

### 3.1 参考：全封闭调参要点（整理自 [[260128全封闭轨道新加机制与待测试项]]）

- **出站时机点**：`S_出/速比 + 0.25m`（动力出站行程 + 半个推杆，使落点居中）；主轨 `V_主 = 25 m/min`，速比现场按 `1:1 / 1:1.2 / 1:1.3` 调
- **避让光电最小距离**：`S_min = S_出/速比 + 0.25m + 0.05m`（机械误差按 2cm）；离最右边沿再加 `0.06m`（进到出距离修正）
- **26/2/6 定稿**：避让光电离出站口 1000mm、误差 ≤2cm；与避让读卡器重叠时 1300mm；两站间距 ≥1800mm；需要安装避让光电时进出站间距最小值 700mm
- **调参注意**：实际落点稍微靠前；避让光电装早了，窗口起点更早、到出站时机点的余量更大；装晚了留给「判定 + 重发 3 次」的时间变短，可能来不及发完
- **未迁移部分**：笔记里的逐站参数表（1250 速度下 1:1 / 1:1.2 / 1:1.3 的一二号站参数）、历次会议纪要与测试记录属现场资料，仍留在笔记，不搬进本文
