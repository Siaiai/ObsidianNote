## 2. 契约 v2（2026-11-19）

- 帧格式沿用 `0xFA CMD1 CMD2 CMD3 LineNo StatNo LenHi LenLo Data`；空推杆上报用**新码 `0xC2`**（`CMD2=0x01`），建议 `Len=2`：`Data[0]` = 去重序号（每站自增或取 `addtime` 低 8 位），`Data[1]` 保留 0，站号走帧头 `StatNo`；去重键 `LineNo + StatNo + 序号`（**帧内容待与上位机确认**）
- 不复用标准线 `0xC1`：它报的是「避让光电触发＝有衣架」，与本需求相反（← D1）
- 判空依据（全封闭模型）：推杆 FIFO `FE_Pole_Fifo_t` 的 `poles[head].occupy == POLE_NO_HANGER`（`0x55`）。来源是双源：`FE_NewPoleDeal` 的读卡判定（推杆到来前 500ms 内读到卡才算有衣架）+ `FE_PoleUpdate` 的避让光电置位（二次保险）
- 时间基准：以**出站落点 = 出站口 = 0**（忽略 0.06 物理偏置）。出站时机点 = `S_出/速比 + 0.25m` = **908mm**；避让光电 = 时机点上游 **25cm** = **1158mm**；读卡器 = `S_进到出` = **1650mm**；出站偏移 `out_shift` =（1650−908）/V = **1781ms**（← C4）
- **待核（参数档位）**：《全封闭轨道电控调试说明》面板截图为 主轨电机速度 **1050**、动力出站速度 **1260**、阀保持 **1500/1900ms**，其「出站偏移(只读)」= **1947ms**（与固件公式一致，对应主轨 21m/min）；而 1781ms 对应主轨 **1250**（25m/min）且忽略 6cm 偏置。现场实际档位待确认——T1-3 验证时刻应按实际 `out_shift` 取（1947 时首帧 ≈ +1590ms、判定窗 1897~1947）
- **仓出站要注意**：进到出 108cm 代入同式只有 **268ms**，小于避让光电提前的 600ms → 「时机点前 25cm」的装法在仓出站不成立（光电会早于推杆入队）；仓出站要么不配避让光电，要么单独定位置（**待现场确认**）
- 光电位置：装在出站时机点上游 **25cm**（半个推杆）→ 触发时刻 = 出站时机点 **前 600ms**（1781−600=1181ms）
- 上报窗口：**`[out_shift−100, out_shift−50)` = 1681~1731ms**（半开区间，紧贴出站判定窗之前、且不与它重叠）；**首发在该窗口内立即发出 → +1681ms**；重发 `+1881 / +2081 ms`（200ms 超时）
- 判空点：光电之后 `occup` 已被定死（光电触发→`0xAA`、未触发→仍 `0x55`）；**上报窗口内 `HEAD.occupy == 0x55` 即空推杆**，不再单独做「光电窗口」判定
- 上报状态宿主：每站一组（`active / sent / seq / due_time / start_time`），**不挂在 FIFO 推杆节点上** → 首发发出后即使 `FE_OutStation` 把 HEAD `PopHead` 清掉，重发照常进行
- 出站判定窗：`FE_OutStation` 的 `WATE_OUT` 只在 `[out_shift−50, out_shift]` = **1731~1781ms** 这 50ms 内判定（原样不动）；首帧在它开窗前 50ms，帧 2 落在窗内、帧 3 在出站动作后，属预期，上位机按序号去重
- 重发：首发 + 2 次重发（共 3 帧），超时 **200ms**；收到上位机应答即停；3 帧后静默丢弃，不报故障
- 版本号：全封闭 v2 线改动必须递增 `ControlVer`（当前 V3.3.05.8）

## 3. 方案

按 `FullyEnclosed.c` 的真实链路实现（← D1 / C2）：

- **判空与起报**：`FE_PoleUpdate` 每轮对 HEAD 算 `dt = now − HEAD.addtime`；当 `dt ∈ [out_shift−100, out_shift−50)` 且 `HEAD.occupy == POLE_NO_HANGER`、本站上报未激活 → 起任务：`active=1 / sent=0 / seq++ / due_time=now / start_time=now`（第一个周期就发首帧）。该窗口严格早于 `FE_OutStation` 的 `[out_shift−50, out_shift]`，`PopHead` 只可能在窗口之后 → 判空时 HEAD 一定还是目标推杆；光电已在 600ms 前把 `occupy` 定死，**不需要再读光电标志、也不需要另做光电窗口**。
- **发送**：沿用现有上报排队——`FE_PROCESS` 每轮 `if (active && now ≥ due_time && sent < 3)`：置 `Command_Data[站].AvoidPDEmpty = 1` + `Command_Num++`，由 `Pc_UDPSend` 发一帧 `0xC2`（每轮一帧，不抢别的上报）；随后 `sent++`、`due_time = now + 200`；`sent == 3` 时 `active = 0` 静默结束。
- **重发保护**：任务状态放在站点结构体（新增 `FE_AvoidReport_t`），`FE_PolePopHead` 清的是 FIFO 节点，碰不到它 → **出站把 HEAD 清掉也不影响重发**；另加 `now − start_time > 3000` 兜底清任务。代码量约：结构体 5 字段 + `FE_PoleUpdate` 8 行 + `FE_PROCESS` 8 行 + `PC_AckDeal` 1 行 + `Pc_UDPSend` 一段帧组装。
- **应答**：`PC_AckDeal` 的 `CTRL_CMD_G1` 分支新增 `case M_CMD_AVOID_PD_EMPTY (0xC2)` → 该站 `active = 0`。
- **帧内容提醒**：`FE_Pole_t` 只有 `addtime / occupy / HangerID / branch_rail`，**没有杆号**；标准线 `0xC1` 是取 `StatParam[站].NowPoleNum`（主轨杆值，带 `PoleValDly` 延迟）上报。0xC2 要带杆号就沿用 `NowPoleNum`，否则只带站内自增序号去重（帧内容仍待与上位机确认）。
- **不动出站逻辑**：`FE_OutStation` 的 `WATE_OUT` 判定（`occupy==0x55` 且 `out_shift−50 ≤ now−addtime ≤ out_shift`）与 `PopHead` 保持原样，上报是旁路，只影响上位机决策。
- **边界**：不改 `out_shift` 计算、不动 `FE_OutBuff`/`FE_PowerOutStateUpload`、不碰标准线 `develop`。
