## 2. 契约 v1（2026-11-18）

- 帧格式沿用 `0xFA CMD1 CMD2 CMD3 LineNo StatNo LenHi LenLo Data`；本次上报的命令码与 `Data` 字段**待定**（标准线 `0xC1` 的语义是「避让光电触发＝有衣架」，与本需求相反，不复用）
- 时序窗口：该推杆经过避让光电之后、到出站时机点之前（`OutValve[站].DlyPole` 杆范围内），上报点尽量靠近窗口末端
- 空推杆判定：复用现有推杆占有模型 `InToOutPoleFlag[站][k] == POLE_NO_HANGER`（`0x55`）；避让光电触发一律记为该推杆有衣架（`0xAA`）
- 重发：首发后超时未收到上位机应答则重发，最多 3 次；超时值待定，且必须短于窗口长度（`DlyPole` 常为 1~3 杆，推杆周期约 1.2s）
- 杆号来源唯一：`StatParam[].NowPoleNum`，由主轨光电驱动刷新；不得另建杆号
- 避让光电安装约束（现场调参定稿）：离出站口约 1000mm、固定位置误差 ≤2cm，最小距离 ≥ `S_出/速比 + 0.25m + 0.05m`；与避让读卡器重叠时 1300mm；站间距 ≥1800mm。上报时刻由光电物理位置与主轨速度决定，固件不做距离补偿
- 版本号：全封闭 v2 线改动必须递增 `ControlVer`（当前 V3.3.05.8）

## 3. 方案

需求已明确到「空推杆 + 超时重发 3 次」，实现参数待定（← D1）：

- **窗口**：`UDP_CMD.c MainRailPD_Deal` 处理新杆值时（`InToOutPoleFlag[]` 移位之后），为该站启动一个「空推杆窗口」，长度按 `OutValve[站].DlyPole` 杆计——起点是避让光电确认之后，终点是出站时机点。
- **判定**：窗口末端（`MotionUnit.c MotionOut` 的 `sIDLE` 分支动作前）查该站对应槽位 `InToOutPoleFlag` 是否为 `POLE_NO_HANGER`；是则本窗口需上报，杆号取 `StatParam.NowPoleNum`。
- **上报**：每站每窗口最多一帧，在 `Pc_UDPSend` 里按站轮询发出（沿用现有 `Command_Data` + `Command_Num` 的排队风格）。
- **重发**：每站一个小状态机（倒计时 `TC` + 已重发次数 + 已报杆号）。首发后等应答，超时未应答则重发，最多 3 次；3 次后放弃并记计数；收到应答或杆号变化立即清窗口状态。
- **不复用 `AvoidPDBan`**：标准线的 `Ban` 语义是「上位机确认后本杆别再报」，本需求是「报给上位机由它决定」，两者不能共用同一对标志。
- **待定参数**（T1-1 要定的）：命令码与 `Data` 字段；超时值；「重发 3 次」是含首发共 3 帧还是首发 + 3 次重发；是否按站 / 按客户做开关。

### 3.1 参考：全封闭调参要点（整理自 [[260128全封闭轨道新加机制与待测试项]]）

- **出站时机点**：`S_出/速比 + 0.25m`（动力出站行程 + 半个推杆，使落点居中）；主轨 `V_主 = 25 m/min`，速比现场按 `1:1 / 1:1.2 / 1:1.3` 调
- **避让光电最小距离**：`S_min = S_出/速比 + 0.25m + 0.05m`（机械误差按 2cm）；离最右边沿再加 `0.06m`（进到出距离修正）
- **26/2/6 定稿**：避让光电离出站口 1000mm、误差 ≤2cm；与避让读卡器重叠时 1300mm；两站间距 ≥1800mm；需要安装避让光电时进出站间距最小值 700mm
- **调参注意**：实际落点稍微靠前；避让光电装早了，窗口起点更早、到出站时机点的余量更大；装晚了留给「判定 + 重发 3 次」的时间变短，可能来不及发完
- **未迁移部分**：笔记里的逐站参数表（1250 速度下 1:1 / 1:1.2 / 1:1.3 的一二号站参数）、历次会议纪要与测试记录属现场资料，仍留在笔记，不搬进本文
