## 2. 契约

- 帧：`FA CMD2 CMD3 LineNo StatNo LenHi LenLo Data`；`0xC2` 用 `CMD2=0x01`、`Len=1`、`Data[0]=0x55`，站号走帧头，**不带杆号、不带序号**
- 判空：出站判定窗 `[out_shift−60, out_shift]` 内 `pole.head.occupy == 0x55`（`POLE_NO_HANGER`）；不读光电标志、不另设光电窗口
- `occupy`：`0x00` 无效 / `0x55` 空 / `0xAA` 有衣架；光电触发把 HEAD 置 `0xAA`
- 去重：按 `addtime`，同一根推杆只报一轮（`avoid_report_addtime`）
- 重发：首发后每 200ms 一帧、共 3 帧；第 3 帧后再等 200ms 无 ACK 则清零放弃（全程 ≤600ms），不报故障
- ACK：上位机回 `FA 81 0D LineNo StatNo Len=3 Data=FA 01 C2` → `FE_AvoidReportAcked` 清 `avoid_send_cnt`
- 闸门：`CtrlParam.RailRun != 1` 或 `AvoidPD[站].PinID == 0` → 不报并清在途；本站非 `wmFullyEnclosed` 或升级中 → 在途清 0
- `out_shift = ((W−25−6)/(rail_speed/30) − trip/(out_speed/30)) × 1000`；默认 W=165、trip=79、out=1500、rail=1250 → **1636ms**（含 6cm 机械偏置）
- 上报不受 `NextFull`、`is_masked`、出站阀未配影响，只看 `RailRun` 与光电配置
- 版本：全封闭线每次改动递增 `ControlVer`（当前 `V3.3.05.9`）

## 3. 方案

### 3.1 链路与顺序

`FE_PROCESS()` 每轮对每个站：`FE_HangerEnterStation`/`FE_PoleEnterStation` → **`FE_AvoidReportDeal`** → `FE_OutStation` → `FE_PowerOutStateUpload`；固定周期部分 `FE_OutBuff` → `FE_NewPoleDeal` → `FE_PoleUpdate` → `FE_HangerToEnterUpdate`。

- 上报必须排在出站之前：出站命中判定窗会 `PopHead` 消费 HEAD，之后再判就判不到
- 上报状态挂 `FE_station_t`（`avoid_report_addtime` / `avoid_send_cnt` / `avoid_send_time`），`PopHead` 清的是 FIFO 节点 → 出站把杆清掉也不影响重发
- 一帧一拍：`FE_AvoidReportSend` 只置 `AvoidPDEmpty` 并 `Command_Num++`，真正组帧在 `Pc_UDPSend`；发送后清位，没收到 ACK 下一拍再置
- 风险：推杆信号漏检会让 HEAD 与实际杆位错位（`LineFD.PushLessFlg` 只报「间隔异常」），漏检那根可能漏报或错报；FIFO 满（20 格）时 `FE_PoleEnqueue` 直接丢弃，同样造成错位

### 3.2 时刻表（`addtime`=0，默认参数 → `out_shift`=1636ms）
