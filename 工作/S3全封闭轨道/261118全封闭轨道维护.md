## 2. 契约 v1（2026-11-19 定稿）

- 帧格式沿用 `0xFA CMD1 CMD2 CMD3 LineNo StatNo LenHi LenLo Data`；空推杆上报用**新码 `0xC2`**（`CMD2=0x01`），`Len=1`、`Data[0]` = 主轨杆号 `NowPoleNum`，站号走帧头 `StatNo`
- 不复用标准线 `0xC1`：它的语义是「避让光电触发＝有衣架」，与本需求相反（← D1）
- 光电位置：装在该站**出站时机点前 25cm**（半个推杆）。速比 1:1.2 下：时机点 907mm，光电 1157mm，窗口 = 250mm ≈ **600ms**。笔记 26/2/6 的「离出站口 1000mm」是早期粗定值（1:1.2 下只给 224ms 窗口），以现场实际安装为准
- 首发时机：**窗口中点**，即出站时机点前 **300ms**；三帧 `−300 / −100 / +100 ms`（相对时机点），第 3 帧落在出站动作之后，属预期，上位机按杆号去重
- 空推杆判定：**双源确认**——进站读卡器与避让光电任一确认有衣架即非空，两者都没读到才判空。避让光电是「衣架芯片损坏、读卡器漏读」的二次保险；代码上即 `InToOutPoleFlag[站][k] == POLE_NO_HANGER`（避让光电触发一律置 `POLE_HAVE_HANGER`）
- 重发：首发 + 2 次重发（共 3 帧），超时 **200ms**；收到上位机应答即停；3 帧后仍无应答静默丢弃，不报故障
- 无分站开关，全站生效
- 杆号来源唯一：`StatParam[].NowPoleNum`，由主轨光电驱动刷新；不得另建杆号
- 版本号：全封闭 v2 线改动必须递增 `ControlVer`（当前 V3.3.05.8）

## 3. 方案

需求与参数均已定稿（← D1），实现按此走：

- **窗口**：从避让光电触发（出站时机点前 600ms）到出站时机点，共 600ms / 0.5 杆（速比 1:1.2、光电 25cm、推杆周期 1.2s）。`UDP_CMD.c MainRailPD_Deal` 处理新杆值时（`InToOutPoleFlag[]` 移位、避让光电已确认之后）启动该站的窗口计时。
- **判定与首发**：窗口走到中点（出站时机点前 300ms）时，读该站对应槽位是否为 `POLE_NO_HANGER`；是则发 `0xC2`（杆号取 `StatParam.NowPoleNum`），并记下已报杆号。
- **重发**：每站一个小状态机（`TC` + 已发次数 + 已报杆号）。首发 `t0 = 时机点 −300ms`，`+200ms`、`+400ms` 各重发一次（即 −300 / −100 / +100ms，第 3 帧在出站动作开始后 100ms）；收到应答或杆号变化立即清状态；3 帧后放弃，静默。**上位机需按杆号去重**。
- **发送位置**：`Pc_UDPSend` 按站轮询，沿用现有 `Command_Data` + `Command_Num` 排队，每轮只发一帧，不抢占其它上报。
- **不复用 `AvoidPDBan`**：标准线的 `Ban` 是「上位机确认后本杆别再报」，本需求是「报给上位机由它决定」，两者不共用。

### 3.1 时机点与距离对照（速比 1:1.2，V_主 = 25 m/min = 0.4167 m/s，1mm = 2.4ms，一个推杆 = 0.5m = 1.2s）

| 时机点 | 距出站口 | 相对出站时机点 | 依据 |
|---|---|---|---|
| 进站读卡器 | 1.59 m | 前 1.64 s | `S_进到出 1.65 − 0.06` |
| 避让光电 | 1.157 m | **前 600 ms** | 装在出站时机点前 25cm（现场口径） |
| 出站时机点 | 0.907 m | 0（基准） | `S_出/速比 0.657 + 0.25` |
| 出站动作完成 | 0 | 后 1.58 s | `S_出/V_出` |

- 三帧：`−300 / −100 / +100 ms`（首发在窗口中点，第 3 帧落在出站动作开始之后 100ms）
- 公式约束：光电须在 `出站时机点 + 0.05m`（机械误差最小）到 `+ 0.5m`（一个推杆）之间；**前 25cm 满足**
- 26/2/6 的 1000mm / 1300mm 是早期值：1:1.2 下 1000mm 只落在时机点前 93mm（窗口 224ms），不够「读卡器漏读后靠光电二次确认」用，已按现场实际 25cm 修正
- **二号站待核**：`进到出 1.73m` 代入公式得偏移 1.52s，参数表却写 0.75（=0.90s），差约 0.6s（半个推杆）；一号站 1.65m 代入得 1.32s，与表格 1.10 完全吻合——二号站以哪个为准需现场确认
- 可交互核对：`D:\S3\docs\避让上报时机仿真.html`（速比 / 光电位置 / 首帧位置可调）
