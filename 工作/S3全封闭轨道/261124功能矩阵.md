## 图例

**差异类型**（四选一，全表无空值、无「待定」）

| 取值 | 含义 |
|---|---|
| 一致 | 两版对同一件事的判定与动作实质相同 |
| 标准超集 | 标准版有、全封闭 v2 没有（多为标准版后续新增的健壮性修复） |
| 全封闭独有 | 标准版没有对应能力，全封闭 v2 新增 |
| 实现冲突 | 两版都做同一件事，但判据、时序、帧语义或数据来源不同，合并时会互相覆盖 |

**建议归属**（四选一）

| 取值 | 含义 |
|---|---|
| 复用 | 直接沿用标准版实现，收口进底座层 |
| 分叉 | 进能力层，用能力位开关走不同实现 |
| 参数化 | 同一套代码，差异收进参数（含端口、距离、时间） |
| 各自独立 | 语义不同、不强行合并，各自留在自己的模块内 |
