# 需求

## Flash 布局

| 地址 | 大小 | 用途 | 谁读写 |
| :--: | :--: | :--- | :----- |
| 0x0000 | 7KB | Bootloader | 仅 bootloader |
| 0x1C00 | 10.5KB | 主程序 | 仅 app |
| 0x4600 | 16B | FlashData_t (升级标志+读卡器参数) | bootloader + app |

> [!note] FlashData_t 布局
> 升级标志和读卡器参数合并在一个结构体，共享同一个 512B 扇区。
> 擦写时整体读-改-写，互不清零。
> - 前 6 字节：BootParam（bootloader 读写，结构必须和 bootloader 一致）
> - 后面：读卡器参数（仅 app 读写）
>
> 升级后 bootloader 只写前 6 字节，读卡器参数变 0xFF -> app 用默认值（不可避免）。

### 0x55 协议帧格式

```
字节:  0     1     2-3        4-5         6~6+Len-1      6+Len  7+Len   8+Len
       0x55  CMD   Len(小端)  PackNo(大端) Data[Len]      CRC_HB CRC_LB  0xAA
```

- CRC: CRC-16/USB (poly=0x8005, init=0xFFFF, refin/refout, xorout=0xFFFF)，仅对 Data 计算
- PackNo/CRC: **大端**（控制器按大端解析）
- Len: 小端

### 升级标志值

| 值 | 含义 |
| :--: | :--- |
| 0xFF | 擦除态，bootloader 直接跳 app |
| 0x00 | rNormal，bootloader 不跳 app，等命令 |
| 0x03 | rUpdated，升级完成，app 上报后清 |

长度不在协议中体现，靠约定长度来进行解析。
**`0xFF`**:卡号相关
**`0xA0`**:下发设置和查询相关，控制器设置参数或查询数据
`0xA1`:上报信息相关，读卡器上报参数

## 模式与功能

> [!note] 约定
> **新卡**：
>  - 有卡的情况下卡号变了
>  - 从无卡到有卡

### 模式表
| MODE | 模式名称 |                          主动行为                           |               被动行为               |    场景    |
| :--: | :--: | :-----------------------------------------------------: | :------------------------------: | :------: |
| 0x00 | 桌面模式 |                  有新卡后发送一次卡号，蜂鸣器响50ms                   |                无                 |  桌面读卡器   |
| 0x01 | 进站模式 | 读到新卡主动上报一次后**间隔一段**时间再次上报<br>若期间**读到新卡**则结束上次上报后开始上报新卡号 | 收到查询指令后不管实际有没有读到卡<br>都上报**没有卡号** |  进站读卡器   |
| 0x02 | 下放模式 |                       读到新卡主动上报一次                        |      收到查询指令后**根据实际情况**上报卡号       | 下放/出站读卡器 |
| 0x03 | 连续模式 |                       周期发送实际读卡情况                        |                无                 |  分拣读卡器   |

### 模式切换与自动适应

> [!note] 拔插自动适应
> 读卡器可以随意拔插换位置，控制器通过 0xFF 查询指令自动切换模式：
> - 控制器发 `0x7A/0x9A` -> 读卡器切进站模式（不存Flash，重启后恢复Flash模式）
> - 控制器发 `0x75/0x95` -> 读卡器切下放模式（不存Flash）
> - 首次收到切模式+Fail，后续收到按模式轮询应答
> - BCC 使能/失能也由 0xFF 指令控制，不存 Flash，重启后恢复 Flash 值

> [!note] 桌面模式硬件检测
> 桌面模式在读卡器上电时通过 PC06 引脚电平判断：
> - PC06 低 = 桌面硬件（蜂鸣器三极管下拉）-> 强制桌面模式 + 写Flash
> - PC06 高 = 非桌面硬件（10K 上拉）-> 若 Flash 存了桌面模式则改为进站 + 写Flash
> - 检测完后 PC06 切为输出（桌面模式驱动蜂鸣器）

> [!tip] 主动和被动
> **主动**:主要是主动上报 **被动**: 主要是对于指令的响应
> 主动行为和被动行为是独立的互不影响，所以等待期间如果有查询也会上报

## 解码方案

### 架构: ISR 只记边沿 → 主循环全解码

**ISR (Bsp_GtimRead)** 只做两件事: 读电平 → 读时间戳 → 压 FIFO。不解码，不判断。
**主循环 (EM4095_Poll)** 从 FIFO 取边沿，走分类 → 状态机 → 校验 → 投票 → 事件输出。

### 事件表
| 事件  |    触发条件     |    说明    |
| :-: | :---------: | :------: |
| CardIn  | 投票出新卡号 | 无卡→有卡 或 卡号变更 |
| CardOut | `now - last_card_ms >= 200ms` | 200ms 没读到卡 |

### 状态机

```html
<div style="display:grid;grid-template-columns:1fr 1fr 1fr;gap:8px;font-size:12px;line-height:1.5;margin:12px 0">

  <!-- IDLE -->
  <div style="background:#2e1e1e;border:2px solid #f38ba8;border-radius:8px;padding:10px 12px">
    <div style="font-weight:bold;color:#f38ba8;font-size:15px;margin-bottom:6px">● IDLE</div>
    <div style="color:#cdd6f4">等帧间隙高电平后的第 <b>一个 LONG 下降沿</b></div>
    <div style="margin-top:8px;padding:4px 8px;background:#1e1e2e;border-radius:4px;color:#a6adc8">
      <span style="color:#a6e3a1">LONG + level=0</span> → <b style="color:#f9e2af">SEEK</b><br>
      <span style="color:#6c7086">其他</span> → 停留 IDLE
    </div>
  </div>

  <!-- SEEK PREAMBLE -->
  <div style="background:#1e2a1e;border:2px solid #a6e3a1;border-radius:8px;padding:10px 12px">
    <div style="font-weight:bold;color:#a6e3a1;font-size:15px;margin-bottom:6px">◉ SEEK_PREAMBLE</div>
    <div style="color:#cdd6f4">收集 ≥16 个 <b>交替 SHORT</b> 边沿, 累加 delta<br>用来测 base_us</div>

      <span style="color:#f38ba8">非SHORT 或 方向不交替</span> → <b>回 IDLE</b>
    </div>
  </div>

  <!-- RECEIVE -->
  <div style="background:#1e1e2e;border:2px solid #89b4fa;border-radius:8px;padding:10px 12px">
    <div style="font-weight:bold;color:#89b4fa;font-size:15px;margin-bottom:6px">◎ RECEIVE</div>

      <tr><td style="padding:3px 6px;color:#a6adc8">④ 列偶校验</td><td>4 列 × (每列 10 数据 + 1 校验位)</td></tr>
    </table>
    <div style="margin-top:8px;padding:6px 8px;background:#1a1a2e;border-radius:4px;color:#a6adc8">
      全过 → 提取 5 字节卡号, 入投票 FIFO<br>
      <span style="color:#f38ba8">任一失败 → <b>回退 IDLE + 回放边沿环形缓冲</b> (不丢帧间隙数据)</span>
    </div>
  </div>

  <div style="background:#1e1e2e;border:2px solid #cba6f7;border-radius:8px;padding:10px 14px">
    <div style="font-weight:bold;color:#cba6f7;font-size:14px;margin-bottom:8px">🗳 VOTE (3 帧 FIFO, 2/3 一致)</div>
    <div style="color:#cdd6f4">
      <div style="margin-bottom:6px">FIFO 存最近 3 帧卡号, 新帧顶旧帧</div>
      <table style="width:100%;color:#cdd6f4;border-collapse:collapse;margin-bottom:8px">
        <tr style="color:#a6adc8"><td>2 帧时</td><td>两帧一致 → 通过, 不一致 → 等第 3 帧</td></tr>
        <tr style="color:#a6adc8"><td>3 帧时</td><td>取 ≥2 票的卡号 → 通过</td></tr>
      </table>
    </div>
    <div style="padding:6px 8px;background:#1a1a2e;border-radius:4px;color:#a6adc8">
      <span style="color:#a6e3a1">通过 + 新卡</span> → emit <b style="color:#89b4fa">CardIn 事件</b><br>
      <span style="color:#f38ba8">不通过</span> → 回 IDLE
    </div>
  </div>

</div>
```
