🔌 Reader_Init() 初始化流程

向量表 VTOR = 0x1C00 (Bootloader 占 0x0000~0x1BFF)
HW 初始化 EM4095 SHD (PC03 50ms 低脉冲) + Protocol + LED GPIO (PD02/PD03)
升级检查 读 FlashData_t.update_flag
  • rUpdated → 发 55 03 (成功) → 清标志写回 → 继续
  • 异常值 → 发 55 03 (失败) → 清标志写回 → 继续
  • 0xFF/0x00 → 正常启动, 直接继续
    • Flash 加载 flash_init(): 读参数 → 校验 magic → 无效则默认值
    桌面检测 PC06 读电平 → 桌面硬件强制桌面模式 / 非桌面修正模式 → PC06 切输出
    初始 LED Led_SetScene(DESKTOP_NOCARD)
