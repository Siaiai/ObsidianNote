handle_frame — 校验 + 投票

Verify · 4 项校验 verify_frame()

  1. 停止位: bit[63] == 0
  2. 帧头: bit[0..8] 全为 1
  3. 行偶校验: 10 行 × (4 数据 + 1 校验), 每行 XOR = 0
  4. 列偶校验: 4 列 × (10 数据 + 1 校验), 每列 XOR = 0
✓ 全过 → 提取 5 字节卡号, 入投票 FIFO
✗ 任一失败 → 重置解码器回 Idle + 回放 edge_ring 边沿

卡跟踪 · CardOn / CardOff

card_on(id)
① 判断新卡: current_id 全零 或 不等号
② 新卡 → 清投票 + emit CardIn + 入队
③ 更新 current_id + last_card_ms
④ card_present = true
card_off()
Poll 每轮: now - last_card_ms >= 200ms
→ emit CardOut
→ card_present = false
→ 清 current_id + 投票缓冲
