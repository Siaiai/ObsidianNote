## 通信协议
### 指令表
长度不在协议中体现，靠约定长度来进行解析。
**`0xFF`**:卡号相关 
**`0xA0`**:下发设置和查询相关，控制器设置参数或查询数据
`0xA1`:上报信息相关，读卡器上报参数

## 模式与功能

### 模式表
| MODE | 模式名称 |                            主动行为                             |               被动行为               |    场景    | 二代控制器 | S3控制器 |
| :--: | :--: | :---------------------------------------------------------: | :------------------------------: | :------: | :---: | :---: |
| 0x00 | 桌面模式 | 读到卡后发送卡号**ASCII码**发送后**冷却一段时间**<br>再次判断有没有卡，**有卡则再发，没卡就不发** |                无                 |  桌面读卡器   |       |       |
| 0x01 | 进站模式 |   读到新卡主动上报一次后**间隔一段**时间再次上,<br>若期间**读到新卡**则结束上次上报后开始上报新卡号   | 收到查询指令后不管实际有没有读到卡<br>都上报**没有卡号** |  进站读卡器   |   ✅   |   ✅   |
| 0x02 | 下放模式 |                         读到新卡主动上报一次                          |      收到查询指令后**根据实际情况**上报卡号       | 下放/出站读卡器 |   ✅   |   ✅   |
| 0x03 | 连续模式 |                         周期发送实际读卡情况                          |                无                 |  分拣读卡器   |       |       |
