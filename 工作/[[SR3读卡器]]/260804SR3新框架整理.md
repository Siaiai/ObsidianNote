### 现SR3指令表

**`0xFF`**:卡号相关 
**`0xA0`**:下发设置和查询相关，控制器设置参数或查询数据
`0xA1`:上报信息相关，读卡器上报参数

**接收指令**（控制器 -> 读卡器）

| HEAD | TYPE | CMD  | DATA  | 完整字节序列            | 功能                                                                      | 约定长度 |
| ---- | :--: | :--: | :---: | ----------------- | ----------------------------------------------------------------------- | ---- |
| 0x10 | 0xFF | 0x7A |   无   | `10 FF 7A`        | 进站查询+失能BCC+切进站模式                                                        | 3    |
| 0x10 | 0xFF | 0x75 |   无   | `10 FF 75`        | 下放查询+失能BCC+切下放模式                                                        | 3    |
| 0x10 | 0xFF | 0x9A |   无   | `10 FF 9A`        | 进站查询+使能BCC+切进站模式                                                        | 3    |
| 0x10 | 0xFF | 0x95 |   无   | `10 FF 95`        | 下放查询+使能BCC+切下放模式                                                        | 3    |
| 0x10 | 0xA0 | 0x05 |   无   | `10 A0 05`        | 复位读卡器（进Bootloader）                                                      | 3    |
| 0x10 | 0xA0 | 0x01 |   无   | `10 A0 01`        | 查询读卡器版本                                                                 | 3    |
| 0x10 | 0xA0 | 0x02 |  模式   | `10 A0 02 MODE`   | 设置读卡器模式<br>MODE `00`:桌面<br>MODE `01`:进站<br>MODE `02`:下放<br>MODE `03`:连续 | 4    |
| 0x10 | 0xA0 | 0x03 | BCC使能 | `10 A0 03 BCC_EN` | BCC_EN `55`:不带BCC<br>BCC_EN `AA`:带BCC                                   | 4    |
| 0x10 | 0xA0 | 0x04 |  间隔   | `10 A0 04 TIME`   |                                                                         |      |


**发送指令**（读卡器 -> 控制器）

| HEAD | TYPE | CMD  |             DATA             | 完整字节序列                       | 语义       |
| ---- | :--: | :--: | :--------------------------: | ---------------------------- | -------- |
| 0x10 | 0xFF | 0x05 |      厂商编号\[1]+衣架ID\[4]       | `10 FF 05 AA BB CC DD EE`    | 发送卡号     |
| 0x10 | 0xFF | 0x04 |     `46 61 69 6C`:"fail"     | `10 FF 04 46 61 69 6C`       | 发送Fail   |
| 0x10 | 0xFF | 0x06 |  厂商编号\[1]+衣架ID\[4]+BCC\[1]   | `10 FF 05 AA BB CC DD EE BC` | 发送带BCC卡号 |
| 0x10 | 0xA1 | 0x01 | `52 44 33 2e 31 31`:“RD3.11” | `10 A1 01 52 44 33 2e 31 31` | 版本号      |
