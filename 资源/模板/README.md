# 模板索引

> 规范以仓库根目录 `规范.md` 为准。本目录只放模板文件，不放正文笔记。

## 什么时候用哪个

| 场景 | 用哪个 | 位置 |
|---|---|---|
| 日常日志 | Obsidian 模板「日志模板-day」 | `日志模板-day.md` |
| 跨多天、会变更的开发规划 | Form Flow「工作规划」或手动模板 | `规划文档-表单.md` / `规划文档.md` |
| 普通工作任务 | Form Flow「工作任务」 | `资源/form-flow插件/form/工作任务.cform` |
| 其他笔记 | 对应 Form Flow 表单 | `资源/form-flow插件/form/` |

## 模板文件

| 文件 | 用途 | 说明 |
|---|---|---|
| `日志模板-day.md` | 日记 | 执行清单 / 日志 / 今日总结 |
| `规划文档.md` | 规划文档（手动） | 含完整规范注释，复制后改 frontmatter |
| `规划文档-表单.md` | 规划文档（Form Flow） | 只给「工作规划」表单读取，`{{@...}}` 占位符 |
| `README.md` | 本索引 | 新增模板时同步更新 |

## Form Flow 表单

| 表单 | 产出位置 | 关键字段 |
|---|---|---|
| 工作规划 | `工作/{项目}/YYMMDD{名称}.md` | 状态 / 截止时间 / 一句话目标 |
| 工作任务 | `工作/{项目}/YYMMDD{任务}.md` | 类型 / 状态 / 截止时间 |
| 个人任务 | `个人/{项目}/YYMMDD{任务}.md` | 同上 |
| 工作项目 | `工作/项目/{项目名}.md` | 状态 |
| 个人项目 | `个人/项目/{项目名}.md` | 状态 |
| 学习项目 | `学习/项目/{项目名}.md` | 状态 |
| 学习笔记 | `学习/{项目}/{{名称}}.md` | 类型 / 状态 |
| 个人笔记 | `个人/{项目}/{{名称}}.md` | 类型 / 状态 |
| 输出文章 | `输出/{项目}/{{名称}}.md` | 状态 |

## 维护规则

1. **单一事实源**：目录、属性、命名以 `规范.md` 为准；模板只做落地。
2. **两个规划模板必须同步**：改结构时同时改 `规划文档.md` 与 `规划文档-表单.md`。
3. **表单不生成空项**：可选关联字段（相关任务 / 相关项目）不写 `- ""`，留空字段即可。
4. **时间必须带秒**：表单的 datetime 字段只到分钟，内容模板里统一追加 `:00`。
5. **多选类型用 flow 数组**：`类型: [{{@类型}}]`，避免多选值被写成一个字符串。
6. **不改 `.obsidian/`**：表单目录由 Form Flow 的 `data.json` 指定，改目录需同步插件设置。
